# DWP Home three-mode integration evidence

This directory seals the implementation acceptance for three independent Home experiences:

- **Classic (CLASSIC)**: organization portal hierarchy and the approved 18-app launchpad.
- **Flow (FLOW_V1)**: priority-led personal execution and governed widget mesh.
- **MZ (MZ_V1)**: independent agentic workscape with a compact launcher, grounded AI Stage, and review-before-handoff.

The selection API changes only currentMode; it does not overwrite a mode's saved layout. Desktop and mobile browser evidence covers responsive layout, document scrolling, accessibility, partial failures, and the complete 18-app fallback.
