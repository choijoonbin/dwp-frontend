# DWAI·ON 글로벌 경쟁력 재검증 · 고도화 준비 패키지

## 결론

DWAI·ON은 현재 **근거 기반 답변, AI 제안함, 도메인 권한 재검증, 실행 이력과 감사**에서 분명한 제품 방향과 구현 기반을 갖고 있다. 그러나 글로벌 기업용 AI의 핵심 범위인 **보안형 파일 입력, 장기 연구, 내구성 있는 예약 실행, 팀 산출물, 모델 라우팅, Agent 배포·롤백, 지속 평가와 사고 대응**까지 완료된 상태는 아니다.

또한 고도화 전에 닫아야 할 현행 릴리스 차단 항목이 두 개 확인됐다.

- `새 대화`, `내 대화`, `AI 실행 이력`, `전문 에이전트`, `대화 상세` PAGE가 프론트 DRAFT route에는 있으나 공식 제품 권한 레지스트리에 없어 rollout 환경에서 fail-closed될 수 있다.
- AI 제안을 수락한 뒤 action key·입력·근거·proposal ID를 전달하지 않고 일반 행동 목록으로 이동해 제안→업무 실행 검토 문맥이 끊긴다.
- 대화의 `공유`는 ACL 공유가 아니라 현재 URL 복사/Web Share이므로 실제 기능에 맞는 명칭으로 바로잡아야 한다.

따라서 이 패키지는 DWAI·ON을 “전체 완성”으로 선언하지 않는다. 현재 구현과 운영 미연결 영역을 분리하고, 꼭 필요한 고도화만 디자인과 개발에 바로 전달할 수 있도록 정리한다.

## 핵심 제품 결정

1. 공식 route 권한 계약, 제안→action 문맥, 공유 명칭을 먼저 복구한다.
2. DWAI·ON의 대표 가치는 범용 대화가 아니라 **근거 있는 제안에서 안전한 업무 완료까지 이어지는 흐름**이다.
3. 사용자 상위 메뉴는 추가하지 않는다. `새 대화`, `AI 실행 이력`, `내 AI 루틴`, `산출물`, `개인 AI 제어`를 확장한다.
4. 관리자 상위 메뉴는 **`모델 및 라우팅` 한 개만 추가**한다.
5. Agent Studio, Connector 운영, 지속 평가, 사고 대응은 기존 관리자 메뉴 안에서 탭과 상세 화면으로 확장한다.
6. 새 기능은 화면보다 먼저 권한, 버전, 멱등성, 감사, 복구, 운영 지표 계약을 가져야 한다.
