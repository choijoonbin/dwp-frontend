# P13 — 신규 앱 선택안: 작업 캔버스와 러닝

함께 전달: [P00 공통 계약](00-common-contract.md), [앱 확장·신규 앱 계약](../contracts/app-expansion-and-new-app-plan.md).

P00을 적용한다. 이 화면군은 현재 존재하는 앱의 구현 완료 화면이 아니라 신규 제품 기능의 디자인 확장안이다. AI Stage 홈을 깊게 지원하는 Work Canvas를 주력으로 설계하고, Learning & Growth는 별도 선택안으로 설계한다. 메뉴/권한/API가 필요한 NEW_API와 LMS 같은 EXTERNAL을 프레임 밖에 표기한다. 기존 DWAI 아티팩트/Space 확장으로 같은 효용을 충분히 제공한다면 Work Canvas 화면을 해당 앱의 하위 작업 공간으로 채택할 수 있게 관계를 설명한다.

## N01~N06 Work Canvas / 작업 캔버스(가칭)

사용자 질문: “여러 앱에 흩어진 이 작업의 자료·준비·실행을 같은 문맥에서 이어갈 수 있나?” 독립 엔티티는 작업 문맥이다. 원본 업무는 Work/결재/서비스, 자료는 원본 앱, AI 대화와 아티팩트는 DWAI가 소유한다. Canvas는 연결 관계·준비 구성·공유 범위·버전·이력의 owner다. 기본 메뉴는 내 캔버스, 공유받은 캔버스, 보관함, 템플릿, 관리이며 필터·상세를 별도 최상위 메뉴로 쪼개지 않는다.

| ID  | 화면 유형                                | 필드·구조·주 행동                                                                                                                                          |
| --- | ---------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| N01 | 내/공유 캔버스, gallery+list alternative | 제목·목적·owner·업데이트·다음 유효 행동·허용 preview·고정·보관 상태; 새 캔버스·이어하기. 가짜 진척률·사람 점수 금지                                        |
| N02 | 만들기, focus workflow                   | 목적·선택 자료/업무·개인/공유·참여자·template·AI 초안 선택; preview→저장. 검색 없음·미연결·권한없는source 대안                                             |
| N03 | 문맥 작업 공간, adaptive studio          | 문맥 헤더·근거 자료·준비 업무·AI 초안·앱 실행·다음 step·결과; 자료refs/revision과 실제 의무 구분. 타일 벽 대신 실제 작업 중심 공간                         |
| N04 | AI 계획·실행 연결, review workflow       | 요청 의도·scope·근거·제안 steps·대상/입력·확인 필요·원본 도착점·검토 버전; 초안 수정·계획검토·owner handoff. REVIEW≠실행 완료                              |
| N05 | 공유·버전·보관, detail/dialog            | 참여 범위·역할·공유 link lifecycle·원본별 접근 차이·revision diff·보관 이유·복원 가능 조건; 공유 변경/보관/허용 복원. 원본권한 자동부여 금지               |
| N06 | 운영, list-detail+policy                 | 활성 기능·캔버스 수명주기·지원 source·template 버전·허용 capabilities·개인정보/보존·연결상태·감사; validation→게시/적용 확인. 전사 개인본문 기본 노출 금지 |

N03의 시각은 AI Stage 홈에서 확장되는 일관된 공간이어야 한다. 사용자가 업무 문맥을 선택하면 관련 앱·자료·초안이 움직임으로 연결되고 실제 행동은 읽히는 목록/버튼으로 남는다. 드래그-only·정확한 자유 좌표에 의존하는 캔버스는 금지한다. 모바일은 목적→다음 행동→자료→AI 결과→이력 순으로 재배치하고 동일 기능을 목록 대안으로 제공한다. source 변경 시 자동 재배치·포커스 이동 없이 변경 안내와 재검토를 제공한다.

필수 상태: 최초 빈 캔버스, 한 source 실패, 원본 삭제/권한 회수, 자료 revision 변경, 다른 사용자의 수정과 409, 초안 저장 실패, 전송 후 결과 불명, step 부분 성공, 공유 link 만료, 보관된 문맥, unsupported template, offline. receipt는 각 owner의 확정 결과와 관찰 시각이며 범용 자동 rollback을 가정하지 않는다.

## N07~N11 Learning & Growth / 러닝(가칭)

사용자 질문: “내가 선택한 성장을 위해 무엇을 배우고 어디까지 진행했나?” 독립 엔티티는 과정·학습 계획·신청·이수 기록이다. 지식 자료·인사 공식 기록과 구분하며 개인 순위나 성과 감시로 사용하지 않는다. 실제 LMS가 없으면 미연결 상태와 native API 구축 필요를 주석으로 표시한다.

| ID  | 화면 유형                          | 필드·구조·주 행동                                                                                                                       |
| --- | ---------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| N07 | 러닝 홈/내 계획, personal planning | 사용자가 고른 목표·신청한 과정·실제 다음 학습·확인된 진척·필수교육 여부·source; 이어보기/목표수정. AI 제안과 의무교육 구분              |
| N08 | 과정 탐색/상세, list-detail        | 주제·난이도·시간·언어·제공자·수강조건·실제 비용/정원·일정·접근성·자료; 원본 확인/신청. 데이터 없는 비용·추천점수 생성 금지              |
| N09 | 신청/학습, workflow                | 수강조건·개인 계획·승인 필요·대상·확인·제출 결과·owner; native enrollment 또는 LMS handoff·외부권한/결과불명복구                        |
| N10 | 내 기록/공개 범위, personal record | 실제 이수·인증 source·유효기간·증빙·공개 선택·정정 문의; 참고≠공식인사확정·동료 비교 금지                                               |
| N11 | 과정/연계 운영, catalog+policy     | native/external provider·course lifecycle·대상·필수여부·sync freshness·오류·권한·게시/철회·이수 authority; 연결전/partial/정정·개인보호 |

홈 위젯은 “다음 학습/필수 교육”으로 제한된 항목과 원본 행동을 제공한다. AI Stage가 관련 지식을 권할 때는 사용자가 고른 목표·실제 과정 근거를 보여주며 직원 나이·감정·생산성으로 추천하지 않는다. 별도 신규 앱 채택 전에도 해당 UI를 인사/지식/서비스의 연결 흐름으로 제공할 대안을 주석에 제시한다.

## 반환과 신규 앱 계약

N01~~N11 모두 1440/390, 관련 S01~~S15와 320/200%·light/dark·ko/en·키보드·reduced-motion을 반환한다. 주력은 N03/N04이며 나머지 메뉴도 누락하지 않는다. 앱 manifest/메뉴/권한 후보, entity fields·revision·lifecycle·source authority·조회/명령/producer·AI tool과Home widget 연결, 중앙관리/앱관리 경계를 표로 제공한다. 신규 앱을 현재 운영에서 지원된다고 표시하지 않는다.
