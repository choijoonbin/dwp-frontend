# DWAI·ON 홈 · 현재 구현 설명과 확장 브리프

## 제품과 사용자

DWP는 여러 업무 앱이 연결된 테넌트형 Digital WorkPlace다. DWAI·ON은 그 안의 AI 앱이다. 사용자는 AI에게 업무 질문을 하고 근거를 확인하며, 필요한 행동을 원본 앱에서 검토·확정한다. 홈은 회사 포털이나 앱 아이콘 런처가 아니라 **AI와 오늘 어떤 일을 처리할지 고르는 업무 시작 화면**이다.

일반 구성원·팀 리더·회사 관리자가 사용하더라도 개인 홈은 현재 본인에게 허용된 데이터만 보여준다. 관리자 전용 운영 메뉴는 별도 관리 표면이다. 모든 관리 지표를 개인 홈에 섞지 않는다.

## 현재 화면 구조

### A. 공통 셸

DWP 글로벌 헤더, DWAI·ON 제품 사이드바, 테넌트/프로필 문맥을 유지한다. 사이드바는 홈 / 새 대화 / 내 대화 / AI 실행 이력 / AI 제안함 / 전문 에이전트 / 업무 실행 및 연결이다. 기존 권한에 따라 보이는 메뉴가 달라질 수 있다.

현재 홈 본문은 PageCanvas 안에 최대 1480px 중앙 영역을 사용한다. 이 값은 현재 코드 설명이지 향후 모든 화면의 강제 디자인 값이 아니다. 확장 시 공통 셸의 fluid 거터 체계를 우선하고, 읽기 본문에만 국소 최대폭을 둔다. 새 독립 헤더·사이드바를 발명하지 않는다.

### B. 제목과 신뢰 문맥

기존 DWAI·ON 캐릭터, 작은 업무 인텔리전스 문구, 사용자 이름을 포함한 질문형 인사, 권한과 원본 시스템 정책 경계 안내가 있다. 대형 마케팅 히어로가 아니다.

현재 사용자명은 로그인 정보다. 시안에서는 가상 사용자 김민아를 사용한다. 고정 `Live v2.5`, `Pro Active`, 정상 연결 배지 등 확인되지 않은 운영 정보를 넣지 않는다.

### C. 질문 입력

여러 줄 질문 입력, 음성 입력, 전송이 주 행동이다. 입력값이 있어야 전송한다. 전송 중 이중 요청을 막고 실패 시 입력을 보존한다. 실제 질문은 일회성 전달 ID를 통해 새 대화로 연결하며 URL에 문장을 넣지 않는다.

빠른 질문은 오늘 업무 브리핑 / 막힌 업무 찾기 / 회의 준비다. 빠른 질문의 기능은 해당 목적의 요청을 시작하는 것이며 홈 자체가 이미 분석을 완료했다는 뜻은 아니다.

일반 대화의 근거 범위는 업무 항목·메일·일정이다. 결재는 전문 Agent 문맥이 따로 있다. 외부 전사 도구, 무제한 웹 검색, 모든 앱 통합 완료 아이콘을 가짜로 추가하지 않는다.

### D. 업무 신호 5종

| 현재 항목            | 실제 의미                              | 연결              |
| -------------------- | -------------------------------------- | ----------------- |
| 임박 업무            | 업무 큐 summary의 dueSoon              | 업무 큐           |
| 대화 기록            | 현재 로드된 대화 목록 수               | 내 대화           |
| 검토할 AI 제안       | 제안 API의 active 및 highPriority 집계 | AI 제안함         |
| 사용 가능한 에이전트 | 현재 허용되고 UI에서 지원하는 Agent 수 | 전문 에이전트     |
| 검토형 작업          | 현재 허용된 행동 카탈로그 수           | 업무 실행 및 연결 |

현재 값은 조회 결과다. 대화 전체 누적, 직원 생산성, 자동 절약 시간, 성공률로 바꾸지 않는다. 0은 실패가 아니고 미조회/오류는 0이 아니다. 조회 중은 skeleton, 오류는 확인 불가로 분리한다.

### E. 갱신 상태

공통 갱신 영역은 API 조회 상태와 마지막 성공 수신 시각, 새로고침을 보여준다. 실시간 스트리밍 업무 뉴스 피드가 아니다. 현재 일부 자원이 실패하면 실패한 영역을 별도로 알린다. 캐시 수신 시각은 원본 자료의 최신 작성 시각과 다르다.

### F. 우선 업무

공통 업무 큐의 우선순위를 사용해 최대 4건을 제시한다. 제목, 실제 우선순위, 소스 시스템, 사유/요약, 기한/상태와 원문 검토가 있다. 완료된 일을 단지 공간을 채우려고 다시 올리지 않는다. `AI 자동 재배열 완료` 배지는 현재 근거가 없다.

### G. 최근 대화와 전문 에이전트

최근 대화 최대 3건: 제목과 마지막 메시지 시각, 이어가기. 없으면 첫 질문 CTA. 목록에 없는 원문 요약이나 출처 개수를 임의로 만든 카드로 대체하지 않는다.

전문 에이전트: 현재 가능한 일반 업무 Agent와 결재 전문 Agent의 이름·설명·대화 시작. 결재 전문가 권한이 없으면 허용된 것처럼 시작 버튼을 제공하지 않는다.

## 고도화된 홈의 역할

가장 중요한 개선은 `지금 검토할 제안`을 숫자에서 실제 다음 행동으로 연결하는 것이다. 홈은 모든 메뉴의 축소판이 되면 안 된다.

권장 정보 순서:

1. 짧은 인사/현재 범위 + 질문 입력 및 빠른 목적.
2. 처리할 일이 있을 때 가장 중요한 제안 1~2건. 내용은 제안의 최소 근거/검토 사유만 사용. 없으면 빈 큐를 크게 만들지 않는다.
3. 우선 업무와 최근 대화를 주/보조 영역으로 구성.
4. 전문 Agent는 작은 선택 도구. 5종 신호는 비교 가치가 있는 값만 압축하고 화면을 지배하지 않게 한다.
5. 갱신/부분 실패는 각 영역 가까이, 공통 이상만 상단에 요약.

제안 상세→수락→원본 앱 이동의 연결은 반드시 후속 화면 05/06/08과 일치시킨다. 수락을 일정 생성 완료나 메일 발송 완료로 표시하지 않는다.

## 확장은 두 버전으로 구분

**A안: 현재 기반 고도화**

현재 API의 질문/대화/업무/제안/Agent/행동으로 구성한다. 제안 1~2건 노출은 기존 목록 API를 활용할 수 있지만 현행 홈은 집계 중심이므로 신규 UI 작업으로 주석 처리한다. 최근 실패한 run 재개 표시는 신규 UI 및 결과 조회 정합이 필요한 항목으로 구분한다.

**B안: 미래 기능 개념**

활성 루틴이 생겼을 때만 `다음 브리핑 09:00`과 일시중지, 결과물이 존재할 때만 `작성 중 보고서 이어가기`를 추가한다. 스케줄/결과물 서버 계약 전에는 A안에 가짜 항목을 섞지 않는다. 루틴은 초기 단계에서 초안·제안 생성까지이며 원본 앱 자동 변경과 구분한다.

## 중요한 상태

첫 방문 / 모든 데이터 없음 / 제안만 있음 / 일부 API 실패 / 권한 변경 / 소스 갱신 지연 / 질문 전달 실패·만료 / Agent 운영 연결 필요 / 마이크 거부 / 읽기 전용 또는 허용 행동 없음.

403 상태에서는 비공개 제목을 숨기고 현재 계정/조직 확인, 허용된 작업으로 복귀를 제시한다. 503은 재시도, 근거 없음은 범위 조정, 모델 미연결은 운영 준비 안내로 구분한다. 모든 문제를 `권한 요청` 하나로 처리하지 않는다.

## 일관된 가상 디자인 데이터

운영 사실과 혼동하지 않도록 프레임 주석에 `디자인용 가상 데이터`를 표시한다.

- 사용자 김민아, 테넌트 가상 조직, 2026-09-04 09:20, Asia/Seoul.
- 업무: 고객 안내 초안 검토, 오늘 14:00 기한, 높은 우선순위.
- 제안: 내일 회의 준비 항목 확인. 메일과 일정 근거 2건. 검토 전, 자동 실행 없음.
- 최근 대화: 다음 주 회의 준비를 도와줘. 마지막 메시지 09:05, 4개 메시지.
- 빠른 질문: 오늘 처리할 일과 먼저 확인할 근거를 정리해 주세요.
- Agent는 일반 업무/결재 전문 중 실제 시안 역할에 허용된 것만 예시로 사용.

## 반환 요청

1440px 홈과 390px 모바일을 먼저 만든다. 1920/1280/320px 및 200% 확대의 재배치, light/dark/고대비/reduced motion, 긴 제목, 부분 오류 1장과 첫 방문 1장을 포함한다. 헤더·사이드바·공통 거터는 현재 레퍼런스와 정합한다. 질문과 첫 번째 실제 업무가 첫 화면에 함께 보이게 한다.

홈 → 새 대화 → 답변/근거 → 행동 검토, 홈 → 제안 검토 → 원본 앱, 홈 → 내 대화의 이동을 번호 주석으로 연결한다. 특정 API 수치 없는 원형 차트, 항상 흐르는 AI 배경, 무근거 실시간 상태는 요청하지 않는다.
