홈이 이미 만족스럽게 확정됐다면 다시 만들 필요는 없다. 기존 홈 시안을 공통 레퍼런스로 지정하고 02 또는 03부터 이어간다. 이 패키지는 기존 세 시안을 폐기하라는 요청이 아니다.
