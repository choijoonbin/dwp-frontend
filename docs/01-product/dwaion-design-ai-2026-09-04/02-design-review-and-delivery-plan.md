## 4. 디자인 시안 수용 체크리스트

각 항목은 디자인 승인 기준이며 현재 테스트 PASS 주장이 아니다.

- 첫 화면에서 사용자의 질문과 주 행동이 명확하다.
- 메뉴와 상세 패널의 역할이 겹치지 않으며 21화면을 21개 메뉴로 만들지 않는다.
- 질문 전 소스 선택과 답변 후 실제 근거가 구분된다.
- 제안 수락/인계/초안 저장/발송·제출/최종 결과가 다른 상태다.
- 운영 준비·연결 설정·실제 건강 상태·모델 품질을 하나의 녹색 배지로 합치지 않는다.
- 빈 상태/검색 없음/403/503/부분 실패/충돌/만료에 다음 행동이 있다.
- 모바일에서 본문·키보드·고정 입력·플로팅 런처가 겹치지 않는다.
- 공통 셸·거터·한국어/영어·light/dark·고대비·reduced motion과 정합한다.
- 원본 질문/메일·토큰·내부 식별자를 프롬프트 예시에 불필요하게 넣지 않는다.
- 신규 기능은 기존 기능과 다른 프레임 주석으로 표시한다.

자동 반려: 가짜 Live/버전/정확도, 기록 없는 자동 발송 성공, 관리자 개인 원문 무제한 열람, 음성만으로 고위험 확정, 전체를 장식 카드/오로라로 채우기.

## 5. 개발 완료 검증

대표 시나리오를 파일 단위 체크가 아닌 사용자 여정으로 검증한다.

1. 홈 빠른 질문 → 일회성 전달 → 새 대화 → 근거 기반 답변 → 내 대화 재열기.
2. 질문 소스 선택 → 권한 있는 소스만 사용 → 403/503/근거 없음 구분 → 안전한 재시도.
3. 분석 허용 → 지금 분석 → 부분 결과 → 제안 검토 → 수락 → 올바른 입력 검토 → 원본 앱.
4. 소스/제안 revision 변경 또는 세션 변경 → 기존 권위 재사용 차단 → 재검토.
5. 녹음 권한 거부/폐기/전사 실패/검토 수정/전송/TTS 중지.
6. 대화 검색 범위/이름 변경/보존 제한 삭제/일반 실패에서 캐시 정합.
7. Agent 실행 완료와 원본 초안·제출 결과 불일치/부분 성공 복구.
8. 운영자/편집자/검증자/승인자/감사자별 허용·금지 행동 및 자기 승인 차단.
9. tenant/user/session/plane/scope 경계, 원본 owner PEP, stale 권한, 내부 헤더 위조 거절.
10. 1440/1280/390/320px + 200% 실제 확대/리플로, 다크/고대비/감소 모션/키보드, 페이지 overflow와 겹침.

변경 범위에 맞춰 unit/API/PG 경쟁/E2E/OpenAPI generated/typecheck/build/bundle/accessibility를 실행한다. 임계치를 올려 통과시키지 않는다. 실제 공급자/모델 미연결을 fixture 응답으로 정상 판정하지 않는다. 공통 Gate는 소유 세션과 안전 지점을 맞춘다.

## 6. 검토 기록

- 부모 작업: 현재 홈/질문/보관함·라우트/manifest/API, 공식 제품 자료, 전달 패키지 작성.
- 제품/UX 읽기 검토: 제안·행동·실행·도우미·음성. 수락≠실행, 일반 카탈로그 이동, 전사 전 업로드, 원본 초안 저장의 구분을 반영.
- 관리자 아키텍처 읽기 검토: 8개 관리 메뉴와 API. CONNECTED 의미, 평가 PASS 조건, 고정 progress, 감사 export 한도, 보존/원문 권한 분리를 반영.
- 최초 분석 시점에는 런타임/실DB를 재시험하지 않았다. 디자인 수령 후 X01~~X03은 별도
  PostgreSQL에서 V1~~V30 migration과 API·정책·경쟁·격리·암호화 회귀를 실행했다.

최종 문서 교차검토에서 행동 관리의 위험도·필요 권한은 조회 전용이며, 운영 현황의 관련 관리 화면 드릴다운은 신규 UI라는 점을 정정했다. 제품/음성/제안 프롬프트의 현행·신규 구분은 재검토에서 추가 모순이 발견되지 않았다.

패키지 정적 점검: Markdown 26개, 공통 계약 포함 프롬프트 22개, 개별 화면 21개. 기존
navigation의 사용자·관리자 경로와 새 사용자 확장 메뉴 3개를 분석 표와 대조했다. 내부 문서 링크와
화면별 반환물 절도 확인했다. 문서 완전성, UI 회귀, API/DB 검증은 서로 다른 증거로 관리한다.

## 7. 시안 수령 때 필요한 것

디자인 링크 또는 원본 해상도 PNG, 사용한 프롬프트 번호, 확정/미확정 표시, desktop/mobile, 주요 오류 상태, 클릭 흐름을 전달받는다. 우선 홈 공통 방향을 확정하고 답변·제안·행동 검토를 이어간다. 외부 AI에는 실제 개인정보·비밀·운영 원문 대신 가상 데이터만 전달한다.
