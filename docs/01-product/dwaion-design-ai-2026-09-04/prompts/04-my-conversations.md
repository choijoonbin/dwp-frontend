# U04 · 내 대화 보관함

DWP 내부 DWAI·ON 화면의 디자인과 상호작용 명세를 작성하라. 기존 글로벌 헤더·사이드바·캐릭터·토큰을 유지한다. 공통 계약 00-common-design-contract.md를 함께 적용한다. 제품 코드는 아직 만들지 않는다.
현재 기능과 확장은 프레임 주석에서 구분한다. 가짜 Live/정확도/분석 진행률, 장식 오로라·글로우, 카드 안 카드, 큰 환영 히어로를 만들지 않는다. 한국어 기본이며 아래 예시는 모두 디자인용 가상 데이터다.

## 목적과 현재

사용자: 본인의 이전 대화를 찾는 구성원. 질문: “어디서 이어가야 하나?” 주 행동: 대화 열기. Archetype: searchable archive.
경로 /dwaion/conversations. 제목 검색, 최근 24시간/7일/30일, 최신/오래된/메시지 많은 순, 삭제 확인이 있다.

## 현행 데이터 한계

프론트는 기본 최근 30개를 조회한다. 필터와 통계는 이 로드된 목록 기준이다. 제목·마지막 메시지 시각·메시지 수·locale은 있지만 자동 요약·업무 토픽·소스 배지·저장 용량·법적 보존 활성 상태는 목록 계약에 없다.

## 설계

1. 제목, 조회 범위, 새 대화 CTA, 검색과 기간/정렬을 compact toolbar로 묶는다.
2. 반복 행 또는 낮은 강조 카드에 제목·마지막 시각·메시지 수·이어가기. 빈 요약을 임의 생성하지 않는다.
3. 통계는 유용할 때만 “조회된 대화 N개”처럼 범위를 명시한다. 보안 점수·스토리지 원형 차트·직원 생산성 차트는 없다.
4. 더보기 메뉴에서 이름 변경/삭제를 구분한다. 이름 변경은 API가 존재하지만 이번 목록 UI 연결은 신규 UI로 표시한다. Enter/Escape, 저장 실패 시 초안 보존.
5. 삭제 확인에는 대상, 되돌릴 수 없음, 보존 제한 가능성. 성공 후 목록/선택 정합. 삭제 실패를 토스트만 띄운 채 행을 지우지 않는다.
6. 선택한 대화를 닫고 돌아오면 안전한 범위에서 검색/스크롤 유지. 민감한 검색어는 URL로 내보내지 않는다.

## 확장 별도 프레임

전체 보관함 cursor 검색, 본문 검색, 저장된 필터, 다중 선택 내보내기, 요약/태그는 신규 서버 계약 필요다. 다운로드는 범위/권한/감사/만료를 포함한다. 30개 클라이언트 검색을 “전체 검색”으로 바꾸지 않는다.

## 위험 상태

대화 0건, 검색 결과 0건, 조회 실패, 403 권한 철회, 삭제 409 보존 제한, 삭제 404, 재시도.
예시: “내일 회의 준비”, 09:05, 메시지 4개. 정상 3행과 빈 화면을 각각 만든다.

## 반환물

1440px 정상과 390px 모바일, 위 위험 상태 최소 2개를 제공하라. 1280/320px·200% 확대, dark/고대비/reduced motion, 키보드·focus·긴 한/영 문자열 대응을 주석으로 제시한다. 주요 터치 44px, 고정 입력/도우미의 겹침 방지. 클릭→다음 상태→실패 복구를 번호로 연결하고 기존 UI/신규 UI/신규 API/운영 조건부를 구분하라. 정상 그림 한 장으로 끝내지 않는다.
