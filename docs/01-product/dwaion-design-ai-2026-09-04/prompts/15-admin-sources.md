# A03 · 데이터 소스와 커넥터

DWP DWAI·ON의 권한 있는 관리자 화면을 설계하라. 공통 00-common-design-contract.md와 확정한 사용자 홈 디자인 체계를 유지하되 관리 작업에 맞는 정보 밀도를 사용한다. 사용자 메뉴와 별도 관리 표면이며, 관리 권한이 개인 대화 원문 열람 권한을 뜻하지 않는다.
앱 코드는 아직 만들지 않는다. 데이터·명령이 있는 현행 기능과 신규 계약을 주석으로 구분한다. 장식 글로우/오로라, 카드 안 카드, 허구의 Live·정확도·가용률은 금지한다. 예시 값은 가상 데이터다.

## 목적과 현재

사용자: AI 소스 운영자. 질문: “어떤 데이터를 어떤 경계 안에서 참조하나?” 주 행동: 소스 정책 검토/변경. Archetype: governed integration registry.
경로 /dwaion/admin/sources. 7종 소스의 활성화·접근 모드·분류·공급자·connector 참조·정책 버전/수정 시각을 관리한다.

## 설계

1. 소스별 설정 상태, 접근 모드, 분류, 공급자, 수정 시각을 비교 가능한 표로 표현.
2. 선택 상세에 사용 목적, 읽기 범위, 제한과 변경 사유. UPDATE/MANAGE 권한과 버전 충돌을 고려.
3. 비밀값이 아니라 connector 참조 ID를 사용한다. 일반 화면에서 key/token/실제 비밀을 표시하지 않는다.
4. 현재 CONNECTED는 공급자 유형/참조 존재로 계산되는 설정 상태다. UI는 이를 “설정 연결” 수준으로 해석하고 “실시간 정상”으로 바꾸지 않는다.
5. 별도 실제 연결 시험, 마지막 성공/실패, 동기화 지연, ACL 진단은 신규 서버 계약으로 분리한 프레임.
6. 저장은 사유와 현재 policyVersion을 요구한다. 차단 상태인데 동시에 사용 가능한 것처럼 표현하지 않는다.
7. 소스 관리자 권한은 원본 메일/문서 원문 열람을 허용하지 않는다.

## 위험 상태와 검증 과제

미구성, 정책 차단, 저장 충돌, 원본 서비스 403/503, 검사 결과 오래됨, 설정만 있고 live test 없음.
TENANT_ALLOWLIST 같은 설정 라벨이 실제 런타임에서 강제되는지는 별도 검증 필요다. 시안에서 확인되지 않은 접근 제어 보장을 선언하지 않는다.
가상 예시: 캘린더 내부 참조 설정됨, 외부 문서 connector 미설정.
