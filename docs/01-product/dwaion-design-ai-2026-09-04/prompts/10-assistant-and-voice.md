# U10 · 전역 도우미와 음성 경험

DWP 내부 DWAI·ON 화면의 디자인과 상호작용 명세를 작성하라. 기존 글로벌 헤더·사이드바·캐릭터·토큰을 유지한다. 공통 계약 00-common-design-contract.md를 함께 적용한다. 제품 코드는 아직 만들지 않는다.
현재 기능과 확장은 프레임 주석에서 구분한다. 가짜 Live/정확도/분석 진행률, 장식 오로라·글로우, 카드 안 카드, 큰 환영 히어로를 만들지 않는다. 한국어 기본이며 아래 예시는 모두 디자인용 가상 데이터다.

## 목적과 현재

사용자: 현재 앱을 벗어나지 않고 도움을 받을 구성원. 질문: “여기서 무엇을 물어보고 어디로 연결할까?” 주 행동: 질문 또는 도움말 이동. Archetype: contextual assistant.
DWAI·ON 캐릭터 런처와 펼침 패널. 별도 AI 브랜드/앱을 만들지 않는다.

## 기본 도우미

1. 평소 작은 캐릭터/아이콘. hover/focus 이름, 새 상태가 실제 있을 때만 표시.
2. 클릭하면 대화 패널. 데스크톱은 콘텐츠를 임의로 380px 밀지 않는 overlay가 기본이나 콘텐츠/하단 액션을 가리지 않는 도킹·안전 공간 정책을 따른다. 정확 폭은 공통 셸과 검증한다.
3. 모바일은 화면을 덮는 작은 팝업 대신 닫기 가능한 전체 화면 또는 충분한 sheet. 원래 앱으로 focus/스크롤 복원.
4. 질문, 답변/근거, 새 질문, 전체 앱에서 이어가기. 현재 페이지 문맥은 route/app/surface 수준이다. 선택 문서 원문을 자동으로 읽었다고 표현하지 않는다.
5. 이용가이드/담당자/서비스 상태는 보조 도구다. 현재 목적지는 서비스 탐색/직원 디렉터리/앱 목록이다. 전용 튜토리얼, 담당자 배정, 실시간 장애 모니터로 오해되지 않게 한다. 해당 전용 내용은 신규 기능 프레임.

## 음성 상태

명시 시작 → 마이크 권한 → 녹음 → 종료 후 업로드/전사 → 전사문 검토·수정 → 사용자가 전송.
현재 45초 제한의 일괄 STT와 요청형 TTS다. 전사문 검토는 원음 업로드 이후다. 업로드 전 고지와 녹음 폐기 동작을 보완 설계한다. 현재 중지 버튼은 전사로 이어지므로 “폐기”와 구분해야 한다.
TTS는 재생/생성 중/중지/실패. 자동 재생하지 않는다. 텍스트 입력과 읽기를 항상 대안으로 제공한다.
외부 음성 처리자의 보관 정책까지 확인 없이 “어디에도 저장되지 않음”이라고 쓰지 않는다.

## 별도 미래 프레임

실시간 양방향 음성은 자막, 음소거, 명시 종료, 끼어들기, 시간/비용 예산, 연결 실패, 시각적 행동 확인이 필요하다. 현재 STT와 다른 모드로 표시한다. 웨이크워드/상시 청취는 기본값이 아니다.
고위험 행동을 음성 인식 한 번으로 확정하지 않는다.

## 위험 상태

권한 거부, 장치 없음, 녹음 한도, 전사 실패, 잘못 인식된 이름/날짜, TTS 실패, 정책 비활성, 전체 앱 전환 중 만료.
320/390/768px 및 200%에서 본문/하단 행동을 가리지 않는 런처 축소·도킹을 명시한다. Provider 문맥에서는 tenant용 런처를 렌더링하지 않는다.

## 반환물

1440px 정상과 390px 모바일, 위 위험 상태 최소 2개를 제공하라. 1280/320px·200% 확대, dark/고대비/reduced motion, 키보드·focus·긴 한/영 문자열 대응을 주석으로 제시한다. 주요 터치 44px, 고정 입력/도우미의 겹침 방지. 클릭→다음 상태→실패 복구를 번호로 연결하고 기존 UI/신규 UI/신규 API/운영 조건부를 구분하라. 정상 그림 한 장으로 끝내지 않는다.
