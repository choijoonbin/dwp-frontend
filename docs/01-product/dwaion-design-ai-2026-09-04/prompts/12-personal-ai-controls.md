# X02 · 개인 AI 제어: 분석 허용과 데이터 관리

DWP 내부 DWAI·ON 화면의 디자인과 상호작용 명세를 작성하라. 기존 글로벌 헤더·사이드바·캐릭터·토큰을 유지한다. 공통 계약 00-common-design-contract.md를 함께 적용한다. 제품 코드는 아직 만들지 않는다.
현재 기능과 확장은 프레임 주석에서 구분한다. 가짜 Live/정확도/분석 진행률, 장식 오로라·글로우, 카드 안 카드, 큰 환영 히어로를 만들지 않는다. 한국어 기본이며 아래 예시는 모두 디자인용 가상 데이터다.

## 목적과 현재

사용자: AI의 데이터 사용을 통제할 구성원. 질문: “무엇을 허용했고 무엇을 지울 수 있나?” 주 행동: 범위 확인 후 변경. Archetype: preference form.
현재 제안함의 분석 허용/지금 분석/제안 비우기가 있다. 별도 최상위 설정 메뉴를 즉시 만들지 않고 제안함·도우미의 문맥 설정으로 확장한다.

## 현재 기반 화면

1. 업무 신호 분석 허용: 수동 분석을 실행할 수 있는 설정임을 명확히. 상시 감시/스케줄 허용으로 확대 해석하지 않는다.
2. 데이터 비우기: 제안 데이터와 분석 결과를 지우는 범위, 원본 업무/메일/일정은 유지, 감사 메타데이터는 정책대로 보존됨을 구분.
3. 허용 해제와 삭제는 별도 명령. 허용 해제만으로 과거 제안이 모두 삭제됐다는 안내 금지.
4. 저장 중·반영 완료·실패·다른 창 변경을 표시. 실패했는데 switch만 유지하지 않는다.
5. 개인 언어·지역·접근성은 기존 DWP 설정으로 연결한다. 같은 언어 설정을 두 군데 복제하지 않는다.

## 별도 신규 메모리 프레임

명시적으로 기억시키는 선호만: 응답 길이/선호 형식 등. 개인 민감 정보 자동 추론 금지.
각 메모리의 내용, 저장 이유, 출처, 범위, 수정/삭제. 저장 전 검토, 전체 비활성화, 삭제 결과. 팀 메모리는 개인과 별도 동의/권한.
현재 메모리 저장소·관리 API가 없으므로 정상 운영 프레임에 섞지 않는다.

## 위험 상태와 예시

분석 비활성 상태에서 지금 분석 disabled, 삭제 중 분석 요청, replay한 이전 결과, 일부 삭제 실패, 법적 보존 제약, 만료 세션.
예시: 분석 허용 해제는 적용됐지만 보존되는 감사 메타데이터를 솔직히 안내한다.
화면을 법무 문서로 채우지 말고 영향 요약과 상세 정책 링크로 나눈다.
