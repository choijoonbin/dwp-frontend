# DWAI·ON 캐릭터 정의

- 공식명: `DWAI·ON`
- 시스템 표기: `DWAION`
- 한국어 발음: `디웨이온`
- 의미: `DW` Digital Workplace + `AI` Artificial Intelligence + `ON` Always On
- 브랜드 문장: **당신의 업무를 연결하는 DWP AI**
- 영문 문장: **Digital Workplace AI, always on.**

## 캐릭터와 사용 원칙

- 연결 리본이 AI 코어를 감싸는 3번 시안을 대표 캐릭터로 사용한다.
- 기본 자산은 `/assets/assistants/dwaion-link-v1.png`이다.
- 최초 적용 범위는 개인 홈의 우측 하단 플로팅 런처와 대화형 지원 패널이다.
- 런처는 화면을 밀지 않는 오버레이이며, 권한이 있는 지원 경로만 보여준다.
- 패널은 빠른 질문·이용 가이드·담당자·앱 상태를 연결하고 긴 답변은 DWAI·ON 워크스페이스로 승계한다.
- 기본 모션은 미세한 부유와 빛의 맥동으로 제한하고 Reduced Motion 설정을 따른다.
- 상용 출시 전 KIPRIS·WIPO 기준 상표 검토를 완료한다.
