# DWP 캘린더 글로벌 벤치마크 및 제품 설계

- 상태: Implemented R1 baseline
- 기준일: 2026-08-14
- 범위: 개인·조직 일정, 가용 시간, 공간·자원 예약, 시간 인사이트, 운영 정책
- 후속 문서: `../03-architecture/R1 Enterprise Calendar Scheduling ADR.md`

## 1. 조사 정의

캘린더 제품에는 공인된 단일 글로벌 순위가 없다. 이 문서의 `10개 제품`은 매출 순위가
아니라 기업 일정, 외부 예약, 자동 최적화, 다중 캘린더, 자원 운영과 협업 조율을 대표하는
벤치마크 집합이다. 공개 리뷰의 인상평이 아니라 각 공급사의 공식 제품·도움말에서 확인된
기능을 기준으로 비교했다.

## 2. 결론

DWP 캘린더는 월간 그리드 복제품이 아니라 **Time & Space Operating Workspace**여야 한다.

1. 첫 화면은 `오늘 무엇을 준비하고, 참여하고, 조정해야 하는가`를 답해야 한다.
2. 일정 생성은 사람, 시간, 공간, 온라인 회의와 조직 정책을 한 흐름으로 연결해야 한다.
3. 가용 시간 계산은 타인의 제목·메모를 노출하지 않고 free/busy만 사용해야 한다.
4. 집중 시간, 과부하, 충돌은 설명 가능한 개인 인사이트로 제공해야 한다.
5. 운영자는 자원·승인·정책·집계만 관리하며 개인 비공개 일정 본문을 열람하지 않는다.
6. Google·Microsoft는 외부 커넥터이고, DWP 네이티브 일정과 권한 모델의 소유권을 대신하지 않는다.

## 5. 화면 설계 원칙

### 5.1 첫 화면은 달력이 아니라 오늘의 의사결정 화면

월간 그리드는 탐색에는 좋지만 오늘의 행동 우선순위를 알려주지 않는다. DWP 홈은 다음
일정, 회의 참여, 응답 대기, 공간 상태, 집중 목표와 조치 항목을 첫 뷰포트에 배치한다.
장식형 Hero나 중첩 Card는 사용하지 않고 업무 정보의 위계를 Surface·Divider·상태색으로 만든다.

### 5.2 일정 화면

- Desktop은 주간 보기를 기본으로 하고 충분히 넓을 때만 미니 달력을 함께 표시한다.
- Mobile은 날짜별 목록 보기를 기본으로 하며, 날짜 헤더를 고정해 긴 목록의 맥락을 유지한다.
- 주·월·목록은 Segmented Control로 전환한다.
- 빈 시간 클릭, `새 일정`, 집중 시간 제안, 자원 예약이 같은 작성 Dialog를 재사용한다.
- 이벤트 전체 행과 내부 명령은 중첩 버튼 없이 별도 접근성 계약을 갖는다.

### 5.3 가용 시간과 개인정보

- 참석자 이름은 People Directory에서 찾되 계산 API에는 person public ID만 전달한다.
- 서버는 free/busy 구간만 계산하고 타인의 제목, 설명, 위치를 반환하지 않는다.
- 후보는 근무시간, 요청 길이, 충돌 여부와 시간대에 의해 설명 가능한 점수로 정렬한다.
- 선택한 후보는 참석자와 시간이 채워진 일정 작성으로 연결된다.

### 5.4 사용자와 관리자 구분

사용자 메뉴는 오늘, 일정, 가용 시간, 공간·자원, 시간 인사이트다. 관리자 메뉴는 운영 현황,
공간 운영, 일정 정책이며 `ADMIN.CALENDAR` 권한이 있을 때만 노출된다. 테넌트 관리자라는
이유만으로 정책 변경이나 예약 결정을 허용하지 않는다.

## 6. DWP 차별화

| 차별화                          | 설명                                                                                       |
| ------------------------------- | ------------------------------------------------------------------------------------------ |
| Today Command Center            | 달력보다 오늘의 준비·참여·응답·집중 균형을 먼저 보여준다.                                  |
| People-aware Scheduling         | HR People의 영속 식별자와 IAM 사용자를 브리지해 인사 연동 이후에도 참석자 관계를 보존한다. |
| Privacy-preserving Availability | 타인의 일정 본문 없이 free/busy와 근무 정책만으로 후보를 계산한다.                         |
| Governed Space Booking          | 자원별 즉시 확정·운영 승인, DB·서비스 이중 충돌 차단, 결정 사유와 감사 이벤트를 제공한다.  |
| Personal Time Coach             | 회의·집중·과부하·충돌을 설명 가능한 개인 제안으로 제공한다.                                |
| Delegated Administration        | 회사 관리자와 별개의 기능 관리자에게 최소 권한으로 운영을 위임한다.                        |
| Adapter-ready Core              | Native, Google, Microsoft, Approval, HRIS 일정을 같은 정규 모델로 투영할 수 있다.          |

## 8. R1 이후 외부 의존 작업

아래 항목은 설계 누락이 아니라 공급사 Tenant·OAuth Credential·Webhook Endpoint가 있어야
완료 가능한 연동 작업이다.

- Google Workspace·Microsoft 365 양방향 증분 동기화와 재조정
- Google Meet·Microsoft Teams 회의 URL 발급
- 공급사 Push Notification/Webhook 검증과 재처리 Dead-letter 운영
- 외부 예약 링크, 다자간 Poll, 조직 표준 회의 템플릿
- 이동 시간·근무 위치·휴일 캘린더의 외부 시스템 연동
