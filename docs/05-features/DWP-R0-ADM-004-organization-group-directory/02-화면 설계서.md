# 02 화면 설계서

- Route: `/admin?view=directory`
- Mode: `Organizations`와 `Groups` Segmented Control
- Toolbar: 서버 검색, 상태 Filter, 신규 생성, Refresh와 전체 건수
- Desktop: 이름·Key, Parent, Member, Source, Status, Revision과 Action Data Grid
- Mobile: 동일 의미를 유지하는 Semantic List와 Page 이동
- Organization Dialog: 불변 Key, Name, 유효한 Parent와 Description
- Group Dialog: 불변 Key, Display Name과 Description
- Member Dialog: 서버 사용자 검색, 현재 Member 유지, 조직 이동 Source 표시와 저장
- Lifecycle Dialog: 활성화·비활성화 영향 확인

`SCIM managed` 행은 편집·Member·Lifecycle Action을 비활성화하고 Tooltip으로 Source를
표시한다. 비활성 레코드에는 Member Action을 제공하지 않는다. `sm` 미만에서는 Data
Grid를 Mount하지 않아 숨은 Grid Layout 오류를 방지한다.

Loading, Empty, Error, Conflict와 Permission은 Admin 공통 Pattern을 재사용한다.
