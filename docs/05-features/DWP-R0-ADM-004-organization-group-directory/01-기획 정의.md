# 01 기획 정의

## 문제

조직과 그룹을 DB에서 직접 관리하면 Tenant 오염, 순환 조직, 외부 IdP 데이터 덮어쓰기,
소속 변경 뒤 오래된 Session과 감사 누락이 발생한다.

- Persona: Tenant Admin, Identity Operator, Security Reviewer
- JTBD: “조직 계층과 업무 그룹을 안전하게 유지하고 사용자 소속 변경의 영향을 즉시
  회수·추적한다.”
- KPI: Cross-tenant 0건, 조직 Cycle 0건, 변경 Audit 100%, 변경 사용자 Active Session
  0건, 외부 소유 레코드 로컬 변경 0건

## 범위

- Organization Unit 생성·수정·상태와 Parent
- 사용자별 기본 조직 Assignment와 조직 간 이동
- Directory Group 생성·수정·상태와 직접 User Membership
- 검색, 상태 Filter, Page, Source 표시와 Revision

## Non-goal

- SCIM Endpoint와 IdP 실제 동기화
- 중첩 Group과 Group-to-Group Membership
- Group Role·ABAC·Effective Permission 계산
- 조직·그룹 Hard Delete, 사용자 생성과 HR Master 편집
- Agent의 자율 Directory 변경
