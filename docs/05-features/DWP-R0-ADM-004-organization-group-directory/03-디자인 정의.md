# 03 디자인 정의

- 운영 화면은 장식적 Card 대신 전체 폭 Toolbar, Keyline과 고밀도 목록을 사용한다.
- 조직은 `Building2`, 그룹은 `UsersRound`, Directory는 `Network` Lucide Icon으로 구분한다.
- Key는 보조 정보, 사람이 읽는 이름은 주 정보로 배치한다.
- Status와 Source는 색상뿐 아니라 `Active`, `Inactive`, `Local`, `SCIM managed` Text를
  함께 표시한다.
- 명령은 Edit, Members와 Power Icon Button으로 제공하고 Tooltip·Accessible Name을
  부여한다.
- 멤버 이동과 Session 폐기는 저장 전 Action Impact 영역에서 전달한다.
- Desktop Grid의 모든 Column Header에는 식별 가능한 이름을 두고 Mobile은 `ul/li`
  의미 구조를 사용한다.
- 390px Mobile에서 검색·상태·생성·Refresh가 겹치지 않고 명령은 한 행에 유지된다.
