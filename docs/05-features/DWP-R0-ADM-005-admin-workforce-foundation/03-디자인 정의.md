# 03 디자인 정의

- Admin은 마케팅형 Card Dashboard가 아니라 조용하고 밀도 높은 운영 Surface를 사용한다.
- Sidebar Group Header 44px, Child 40px 이상, 최대 2단계
- Hover 없이 Click·Keyboard로 모든 Destination에 접근 가능해야 한다.
- 선택 상태는 Color만 사용하지 않고 Indicator, Weight와 `aria-current`로 표현한다.
- Expanded Inline Menu가 기본이며 Right Flyout은 향후 Compact Rail의 Click 보조 수단이다.
- Desktop Main Canvas는 Sidebar 폭만큼 유동적으로 재배치한다.
- Mobile Drawer가 닫히면 Focus는 Menu Trigger로 복원된다.
- Light·Dark·High Contrast, 200% Zoom과 Reduced Motion을 공통 정책으로 따른다.

## Organization Design Surface

- 조직도는 React Flow 기반 무한 Canvas로 제공하고 Zoom·Pan·Fit·방향 전환을 지원한다.
- 조직, 사람, 직위 Node는 동일 크기 규칙을 사용하며 상태 변화가 Layout Shift를 만들지 않는다.
- Direct·Matrix 관계는 선 종류와 Legend를 함께 사용해 색상만으로 구분하지 않는다.
- Intelligence 기본 Surface는 Dark Decision Canvas와 Light Action Queue를 병치해 분석과 행동을 분리한다.
- Risk Point는 상태 색, 외곽선, 크기를 함께 사용하며 Tooltip과 Keyboard Button으로 동일 정보를 제공한다.
- Data Table은 정밀 조회·Export의 보조 수단이며 첫 화면의 주된 표현 방식으로 사용하지 않는다.
