# 07 수용 테스트

## 자동 Gate

- [x] Auth·Platform·People Flyway가 빈 PostgreSQL에 순서대로 적용된다.
- [x] Tenant Composite FK가 다른 Tenant의 Parent·Member 연결을 거부한다.
- [x] Group Role은 Active·Tenant Scope·유효기간일 때만 Effective Role에 포함된다.
- [x] 미래·만료·Eligible·Scoped Role은 단순 Tenant 권한으로 승격되지 않는다.
- [x] 재입사, 복수 Work Relationship과 미래 Assignment Slice가 저장된다.
- [x] Restricted Identifier에 평문 Column이 없다.
- [x] Admin Desktop·Mobile Navigation, Deep Link와 Axe가 통과한다.
- [x] 일반 업무 Sidebar가 Admin Route에 나타나지 않는다.
- [x] Agent Admin Intent의 Version·Tenant가 Plan Hash를 변경하고 Mutation은 금지된다.
- [x] 조직·사람·직위 Graph와 Direct·Matrix 관계를 동일 기준일로 조회한다.
- [x] 조직·직위 이동 Cycle과 재직자·하위 직위가 있는 직위 종료를 Backend가 거부한다.
- [x] 시나리오 Submit·Approve·Publish가 Decision Gate와 Baseline Drift를 재검증한다.
- [x] 시나리오 복제가 기준 지문·원본 계보·전체 변경 집합을 보존한 독립 Draft를 만든다.
- [x] 두 시나리오의 기준일·기준 지문이 같을 때만 인원·FTE·비용·Span·Layer·품질 차이를 계산한다.
- [x] 검증 근거가 Append-only Table에 저장되고 History API와 UI에서 조회된다.
- [x] Risk Map·Action Queue·Position Plan이 Chromium과 iPhone 13 E2E 및 Axe를 통과한다.
- [x] 시스템 코드 계약 Registry와 각 Service DB의 CHECK·FK 강제값이 일치한다.
- [x] Java Main Source의 모든 Enum이 명시적 코드 Set과 일치하고 값·Binding 변경은
      `schema_version`을 자동 증가시킨다.
- [x] 시스템 코드 전체 Inventory·Binding 증적은 관리자 경로에만 노출되고 Runtime 응답은
      등록된 UI 선택값 Projection으로 제한된다.
- [x] 합성 Workforce 계정은 비특권 `WORKSPACE_MEMBER`만 가지며 관리자 역할을 대량 상속하지 않는다.

2026-08-12 Local Gate에서 Auth V35·People V33·Platform V48·Provider V25를 포함한 각 서비스 최신
PostgreSQL Migration,
Cross-tenant FK, Group Role Query와
People Rehire/Future Assignment SQL Contract를 검증했다. Frontend Playwright는 Chromium과
iPhone 13 Project에서 Admin·Directory 전체 흐름을 통과했고 Agent는 44개 Contract Test를
통과했다. 실제 API로 177명·67개 조직·187개 직위 그래프, 계보 기반 복제와 `+2 FTE`,
`+3.6억 KRW`, `+1 Open Position` 대안을 재현했다. 177개 구성원 계정은 비밀번호 없는
`INVITED` 상태와 결정적 역할 배분으로 Auth에 연결했다. Back/Forward 전용 Navigation Test와
수동 Browser Navigation 보강은 후속 Hardening 범위다. 코드 계약 Gate는 GitHub Actions에서
빈 PostgreSQL·Redis와 Auth·Platform·People·Provider를 기동해 모든 Migration을 적용한 뒤
실행한다. 로컬과 CI 감사는 317개 계약, 1,187개 활성값, 362개 Binding의 누락과 고아 참조를
검사하며 DB `CHECK`·FK뿐 아니라 개인 설정 JSON, 홈 위젯, API 이력·감사 필터 및 서비스 간
기본 역할, 공통 오류, 감사 전달, Connector 계약과 Java Enum 전수 Inventory도 포함한다.
Runtime Code API는 `runtime_visibility=ADMIN_ONLY`인 보안 역할 Code Set을 404로 숨기고,
관리자 Inventory는 일반 역할과 Runtime Token을 각각 403·401로 거부한다.
