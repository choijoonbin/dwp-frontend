# 07 수용 테스트

## 자동 Gate

- [x] Auth·Platform·People Flyway가 빈 PostgreSQL에 순서대로 적용된다.
- [x] Tenant Composite FK가 다른 Tenant의 Parent·Member 연결을 거부한다.
- [x] Group Role은 Active·Tenant Scope·유효기간일 때만 Effective Role에 포함된다.
- [x] 미래·만료·Eligible·Scoped Role은 단순 Tenant 권한으로 승격되지 않는다.
- [x] 재입사, 복수 Work Relationship과 미래 Assignment Slice가 저장된다.
- [x] Restricted Identifier에 평문 Column이 없다.
- [x] Admin Desktop·Mobile Navigation, Deep Link와 Axe가 통과한다.
- [x] 일반 업무 Sidebar가 Admin Route에 나타나지 않는다.
- [x] Agent Admin Intent의 Version·Tenant가 Plan Hash를 변경하고 Mutation은 금지된다.

2026-08-10 Local Gate에서 빈 PostgreSQL Migration, Cross-tenant FK, Group Role Query와
People Rehire/Future Assignment SQL Contract를 검증했다. Frontend Playwright는 Chromium과
iPhone 13 Project에서 Admin·Directory 전체 흐름을 통과했고 Agent는 14개 Contract Test를
통과했다. Back/Forward 전용 Navigation Test와 이 SQL Contract의 CI Container 자동화는
다음 Hardening에서 추가한다.
