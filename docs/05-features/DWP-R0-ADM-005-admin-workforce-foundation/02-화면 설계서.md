# 02 화면 설계서

## Shell

- `/admin`: 일반 업무 Sidebar가 없는 Tenant Control Center
- Header: Product Home, Control Center Label, Tenant Context, Search, Language, Notification,
  Account
- Desktop: 272px Admin Sidebar, 2단계 Inline Expand
- Mobile: 동일 Navigation을 Drawer로 제공

## Navigation

| Group           | 현재 노출 View                           |
| --------------- | ---------------------------------------- |
| Experience      | Branding, Home experience, Announcements |
| People & Access | Users & access, Organization & groups    |
| Platform Setup  | Reference data, Product registry         |
| Governance      | Audit log                                |

미구현 메뉴는 노출하지 않는다. Active Route의 Parent는 자동 확장되고 Child Link는
`aria-current=page`를 제공한다.

## Page Header

각 View는 Generic `Administration` 제목 대신 현재 Capability 이름, 짧은 설명과
`Tenant scoped` 상태를 표시한다. Filter·Create·Export는 각 Manager의 Toolbar가 소유한다.
