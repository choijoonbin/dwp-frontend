# 02 화면 설계서

## Shell

- `/admin`: 일반 업무 Sidebar가 없는 Tenant Control Center
- Header: Product Home, Control Center Label, Tenant Context, Search, Language, Notification,
  Account
- Desktop: 272px Admin Sidebar, 2단계 Inline Expand
- Mobile: 동일 Navigation을 Drawer로 제공

## Navigation

| Group           | 현재 노출 View                           |
| --------------- | ---------------------------------------- |
| Experience      | Branding, Home experience, Announcements |
| People & Access | Users & access, Organization & groups    |
| Platform Setup  | Reference data, Product registry         |
| Governance      | Audit log                                |

미구현 메뉴는 노출하지 않는다. Active Route의 Parent는 자동 확장되고 Child Link는
`aria-current=page`를 제공한다.

## Page Header

각 View는 Generic `Administration` 제목 대신 현재 Capability 이름, 짧은 설명과
`Tenant scoped` 상태를 표시한다. Filter·Create·Export는 각 Manager의 Toolbar가 소유한다.

## Organization Intelligence

- 기본 View는 전체 표가 아니라 `Portfolio Risk Map + Priority Action Queue`다.
- Risk Map의 X축은 관리 범위, Y축은 위험도, 점 크기는 조직 규모를 나타낸다.
- 선택한 Risk Point와 Action Row는 동일 조직 Graph Inspector로 연결된다.
- 정밀 지표 목록은 비교·내보내기를 위한 2차 Surface로 유지한다.
- Changes는 Before/After와 Headcount·FTE·Cost·Layer·Health Delta를 먼저 보여준다.
- Data Quality는 심각도, 대상, 문제, 권장 정비 작업 순서로 보여준다.

## Organization Scenario

- 오른쪽 Drawer에서 시나리오 목록, Decision Pack, 변경 편집, 승인·게시를 한 흐름으로 제공한다.
- 지원 변경: 조직 이동, 직위 이동, 직위 신설, 공석 직위 종료
- Decision Pack은 준비도, 차단·주의 수, 영향 지표, 정책 Check, 불변 검증 이력을 표시한다.
- DRAFT에서만 편집하며 Submit·Approve·Publish마다 Backend가 동일 Check를 다시 실행한다.
- Desktop Drawer는 800px, Mobile은 전체 폭이며 날짜와 상태 Label은 줄바꿈으로 의미가 분리되지 않는다.
