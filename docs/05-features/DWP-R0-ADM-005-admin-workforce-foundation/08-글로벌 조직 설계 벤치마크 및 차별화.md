# 08 글로벌 조직 설계 벤치마크 및 차별화

## 결론

DWP 조직도는 연락처용 Tree가 아니라 `Effective Organization Graph + Workforce Design +
Governed Decision Pack`으로 정의한다. 모든 경쟁 제품의 기능 수를 한 번에 추월한다는 주장은
검증할 수 없다. 대신 구조 변경의 실행 가능성, 근거 재현성, Agent 연결 안전성을 제품 차별 지표로
관리한다.

## 조사 기준

- 기준일은 2026-08-11이며 제품사 공식 문서·Help Center·Release Note만 기능 근거로 사용한다.
- 마케팅 문구는 기능 존재의 단서로만 보고, 구체 동작은 공식 사용 문서에서 재확인한다.
- “우위”는 기능 개수 주장이 아니라 재현 가능한 수용 지표와 자동화된 차단 통제로 판정한다.

## 구현된 차별화

1. 조직·사람·직위와 Supervisory·Matrix·Functional 관계를 하나의 유효일 Graph로 조회한다.
2. Live 원장과 분리된 Scenario에서 조직 이동, 직위 이동·신설·종료를 계획한다.
3. Headcount, FTE, 연간 비용, Span, Layer, Health, Data Quality Delta를 같은 Decision Pack에 담는다.
4. 기준선 SHA-256 지문, 변경 유효성, 계층 무결성, 설계 정책, 비용 커버리지, 승인, 시행일을 검사한다.
5. Manual·Submit·Approve·Publish 검증 결과를 변경 불가능한 Evidence Row로 보존한다.
6. Risk Map에서 조직 규모·관리 범위·건전성을 함께 보고 Action Queue에서 Graph 근거로 이동한다.
7. Agent는 동일 조회·계획·검증·승인 경계를 사용하며 자율 SQL Mutation을 할 수 없다.
8. 시나리오를 변경 집합·기준선 계보와 함께 독립 Draft로 복제하고 두 대안의 결과를 나란히 비교한다.
9. 기준 지문 또는 통화 기준이 다르면 숫자 차이를 계산하지 않아 거짓 정밀도를 차단한다.

## 남은 Gate

1. Scenario Merge와 세 개 이상 대안의 Portfolio 비교
2. Budget Envelope, 조건부 다단계 승인, Finance·ATS·HRIS 실행 조정
3. Skill·Role·Capability·Workload와 Privacy-safe Collaboration Graph
4. Saved View, Favorite, 탐색 History, PDF·PNG·PPT Decision Package Export
5. Comment, Mention, Notification과 동시 편집 충돌 해결
6. 대규모 Graph Virtualization, 서버 집계, 성능·침투·Tenant 격리 시험

이 항목은 미구현 기능을 숨겨 놓고 “완료”로 취급하지 않는다. 고객 데이터·인프라·보안 계약이
준비되는 순서에 맞춰 각 Gate를 별도 Feature 산출물과 수용 테스트로 승격한다.
