이번 재검증은 사용자 업무 Surface와 관리 Surface의 메뉴 격리, 역할별 직접 URL,
Product Surface 권한 fixture, 권한 회수, Scope 전환, 고위험 OIDC step-up, retry·409·popup
실패 계약을 포함한다. 홈 개인화, 결재함, 위임·대리인·Workflow, 정책 이력, 게시 양식 조회

저장 가능한 권위로 취급하지 않는다.

고위험 issuer 요청에는 Browser가 임의 `contextKey`를 제공하지 않는다. 서버가 exact
surface·scope·revision에서 canonical Context를 파생하고, Browser는 반환된
`contextScopeKey`와 proof만 검증한다. 이 규칙은 client-controlled Context 주입을 막는
보안 계약이며 기존 필드 누락이 아니다.

## 규모·성능 기준

- Reference Scale: Tenant당 활성 Task 100,000건, 이력 10,000,000건, 동시 결정 500 TPS
  후보를 부하 시험 시작점으로 사용하고 실제 고객 상한으로 재승인한다.

- 외부 Fulfillment와 AI 시간은 별도 SLI이며 내부 Decision commit SLO를 오염시키지 않는다.
