# DWP-R1-ADM-006 기획 정의

## 1. 문제와 목표

제품 Registry, 시스템 코드, Navigation, 권한과 Connector가 각 메뉴에 분산되면 변경 전에
소유자와 소비처를 확인하기 어렵다. 단순 자산 목록 대신 Tenant의 실제 자산, 직접·전이
관계와 변경 영향을 탐색하고 운영자가 명시한 관계는 Evidence, Version과 감사를 남긴다.

## 2. 포함 범위

- APP, CONNECTOR, AGENT, TOOL, POLICY, API, DATA_PRODUCT와 운영 기준정보 Projection
- Inventory, Focus Graph, Versioned Impact Analysis와 관계 등록·종료
- 소유자 누락, 고립 자산, 폐기 영향 자동 탐지와 Assurance 검토 Queue
- 오탐, 위험 수용, 확인, 해결 판정과 변경된 Evidence의 자동 재검토
- 검색·종류·Lifecycle Filter, 선택·Depth·View Mode 복구
- Tenant 권한, 낙관적 잠금, Correlation과 Audit

## 3. 제외 범위

- 외부 Backstage·GitOps·Schema Registry 동기화
- Source of Truth를 대체하는 임의 Metadata 편집
- 자동 발견 관계를 운영자 명시 관계처럼 변경하는 기능
- 운영자가 판정 규칙의 게시된 본문을 직접 덮어쓰는 기능

외부 동기화는 `D-17` 결정과 Drift·삭제·충돌·복구 Gate 뒤에 활성화한다.
