# DWP-R1-ADM-006 디자인 정의

- Asset 수보다 선택 자산의 소유·상태·위험과 변경 영향을 우선한다.
- Graph는 관계 탐색 도구이며 장식 배경으로 사용하지 않는다.
- Criticality는 색상과 Label·선 Pattern을 함께 사용한다.
- Inventory Table, Graph와 Inspector가 동일 Selection을 공유한다.
- Desktop은 Inventory/Graph와 Inspector의 2개 Track을 사용한다.
- Node 크기는 이름 길이와 관계 수 변화로 Layout이 이동하지 않도록 제한한다.
- Graph의 모든 Node와 Edge는 Text Inventory에서 같은 정보로 접근 가능해야 한다.
- Assurance는 요약 지표, 검토 Queue와 Evidence Inspector를 한 화면에 연결한다.
- 자동 Finding의 오탐·위험 수용은 일반 편집이 아니라 사유가 필수인 통제 Dialog로 표현한다.
- 규칙 Key·Version과 Evidence Hash는 판단 근거 가까이에 항상 표시한다.
- 320px, 200% Zoom, Reduced Motion, High Contrast와 긴 한영 이름을 검증한다.
