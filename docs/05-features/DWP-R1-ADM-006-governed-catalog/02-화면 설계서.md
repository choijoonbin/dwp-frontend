# DWP-R1-ADM-006 화면 설계서

| Route                     | 사용자       | 운영 질문                                      |
| ------------------------- | ------------ | ---------------------------------------------- |
| `/admin/platform/catalog` | Tenant Admin | 이 자산은 무엇과 연결되고 변경 영향은 무엇인가 |

Page Archetype은 `graph + list-detail + inspector + assurance work queue`다.

1. 운영 Context와 최신 생성 시각을 확인한다.
2. Inventory 검색 또는 핵심 자산 개요에서 Entity를 선택한다.
3. Focus Graph에서 Incoming·Outgoing 관계와 고립 여부를 탐색한다.
4. 변경 유형을 선택해 직접·전이 영향, Risk Score와 차단 Finding을 확인한다.
5. 근거가 있는 관계를 등록하거나 Version 확인 후 종료한다.
6. Assurance에서 활성 규칙 Version과 자동 Finding을 검토한다.
7. Finding의 Evidence·SHA-256을 확인하고 사유와 외부 근거 참조를 포함해 판정한다.

`view=assurance&finding={id}`는 검토 대상과 탭을 복구한다. Graph API와 Assurance API의
부분 장애는 서로 격리하며, Assurance 장애가 Inventory와 Graph를 막지 않는다.

Loading, Empty, No Result, Partial, Truncated, Error, Permission 상태를 구분한다. 선택 Entity가
사라진 URL은 목록을 유지하고 Inspector에서 국소 오류를 표시한다. Graph는 Keyboard로
대체 가능한 Inventory와 관계 목록을 항상 함께 제공한다.
