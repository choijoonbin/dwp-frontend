# DWP-R1-ADM-006 수용 테스트

- `V44__create_tenant_catalog_relationships.sql`과
  `V50__add_catalog_assurance_governance.sql`이 빈 DB와 기존 DB에 적용된다.
- Tenant가 다른 관계는 조회·등록·종료할 수 없다.
- Overview·Graph·Impact가 실제 Projection과 일치한다.
- 존재하지 않는 Entity, 자기 참조, 잘못된 Type과 Stale Version을 거부한다.
- `e2e/wave3-governance.spec.ts`의 Graph→Impact→관계 등록 Journey가 통과한다.
- 동일 E2E의 Assurance Deep Link→Evidence 검토→오탐 판정 Journey가 통과한다.
- 판정 규칙의 차단 Flag와 Criticality Weight 변경이 Impact 결과에 반영된다.
- 정기 평가 감사의 Actor는 `SERVICE`이며 사용자 수동 평가는 실제 User Actor를 기록한다.
- 판정 이력 Update/Delete와 게시 규칙 본문 변경을 DB가 차단한다.
- 해결된 Finding과 Evidence가 바뀐 오탐·위험 수용 Finding이 재탐지되면 재개방된다.
- Inventory가 Graph의 접근 가능한 Text 대체 경로를 제공한다.

외부 Catalog·GitOps의 Drift·삭제·충돌·복구는 `D-17` 승인 전까지 현재 범위의 완료 증거로
간주하지 않는다.
