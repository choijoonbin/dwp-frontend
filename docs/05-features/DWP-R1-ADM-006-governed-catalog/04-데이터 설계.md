# DWP-R1-ADM-006 데이터 설계

`adm_catalog_relations`는 운영자가 명시한 Tenant 관계만 저장한다. Domain Entity는 기존
원장 테이블이 계속 소유하고 Catalog 조회 시 Projection한다.

| Column            | 계약                                    |
| ----------------- | --------------------------------------- |
| `tenant_id`       | 모든 조회·변경의 격리 경계              |
| `source_ref`      | `KIND:KEY` Canonical Source             |
| `target_ref`      | `KIND:KEY` Canonical Target             |
| `relation_type`   | 코드 계약으로 관리되는 방향 관계        |
| `relation_origin` | `DECLARED`, `DISCOVERED`, `SYSTEM`      |
| `criticality`     | 정보·운영·핵심 영향                     |
| `evidence_ref`    | 비밀·개인정보를 포함하지 않는 근거 참조 |
| `metadata`        | 비밀을 금지한 JSON Object               |
| `lifecycle_state` | `ACTIVE`, `RETIRED`                     |
| `version`         | 관계 변경의 낙관적 잠금                 |

자기 참조와 Tenant 간 참조를 금지하고 활성 관계 양 끝 Entity를 검증한다. Retire는 과거 행을
삭제하지 않고 Lifecycle과 감사 이력을 남긴다.

## Compatibility Rule과 Assurance

| Table                              | 역할                                                    |
| ---------------------------------- | ------------------------------------------------------- |
| `sys_catalog_compatibility_rules`  | 전역 Rule Key별 immutable Version과 정규화 본문 SHA-256 |
| `adm_catalog_assurance_findings`   | Tenant·Entity·Rule Version별 현재 자동 Finding          |
| `adm_catalog_finding_dispositions` | 사용자·시스템 판정의 append-only 증거                   |

활성 규칙은 `maximumTraversalDepth`, Critical 직접 소비처와 Retire 차단 여부,
Criticality Weight를 정의한다. 동일 Rule Key의 활성 Version은 하나만 허용한다. 게시된 규칙은
본문·해시·Version을 변경할 수 없고 Lifecycle만 `ACTIVE → SUPERSEDED/RETIRED`로 전이한다.

Finding은 Evidence JSON의 SHA-256, 최초·최근 탐지 시각과 낙관적 잠금 Version을 갖는다. 자동
평가에서 사라진 Finding은 시스템 판정으로 해결한다. `FALSE_POSITIVE` 또는 `ACCEPTED_RISK`인
Finding의 Evidence가 바뀌면 과거 판정을 append-only 이력에 남기고 `OPEN`으로 재개방한다.
