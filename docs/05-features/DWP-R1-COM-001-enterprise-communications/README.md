# DWP-R1-COM-001 Enterprise Communications

## 목표

구성원이 자신에게 필요한 회사 소식과 행사를 빠르게 발견하고, 중요한 정책은 기한 내 확인하며, 편집자와 게시자는 대상과 증적을 통제할 수 있는 엔터프라이즈 소식 앱을 제공한다.

## 사용자 흐름

1. 개인 홈의 `소식` 앱 또는 `새로운 소식` 위젯에서 진입한다.
2. `나를 위한 소식`, `전체 소식`, `필수 확인`, `저장한 소식`을 탐색한다.
3. 콘텐츠 유형과 검색어로 피드를 좁힌다.
4. 상세에서 읽기, 저장, 숨김, 제한형 반응, 관련 작업, 필수 확인을 수행한다.
5. 편집자는 관리 센터에서 콘텐츠·커버·대상·게시 창을 초안으로 저장한다.
6. 게시 책임자는 별도 `APPROVE` 권한으로 검토 후 게시한다.
7. 관리자는 노출, 고유 열람, 작업 클릭, 필수 확인 수를 증적으로 확인한다.

## 화면 계약

### 개인 홈

- 최대 3건만 노출하고 소식 앱으로 연결한다.
- 읽지 않은 건수와 필수 확인 상태를 표현한다.
- 이미지가 있는 콘텐츠는 관리형 썸네일을 사용한다.

### 소식 앱

- 추천 스토리는 실제 콘텐츠 이미지와 텍스트 오버레이를 사용한다.
- 목록은 이미지, 유형, 주제, 발행 부서, 날짜, 예상 읽기 시간을 함께 제공한다.
- 필수 확인 레일은 검색·유형 필터와 무관하게 유지한다.
- 동작은 `prefers-reduced-motion`을 존중한다.

### 관리 센터

- 편집: 유형, 주제, 발행 부서, 원문 언어, 제목, 요약, 본문, 커버, 읽기 시간
- 전달: 중요도, 대상, 추천·고정·숨김 정책, 게시 기간
- 증적: 확인 필요 여부와 기한
- 작업: 내부 DWP 경로 또는 HTTPS URL
- 미리보기: 실제 커버와 구성원 화면 표현, 전달 지표, 거버넌스 정책

## API

| 메서드       | 경로                                   | 책임                |
| ------------ | -------------------------------------- | ------------------- |
| GET          | `/api/platform/v1/communications`      | 개인화 피드와 요약  |
| GET          | `/api/platform/v1/communications/{id}` | 권한이 적용된 상세  |
| POST         | `/events/{eventType}`                  | 상호작용 증적       |
| PUT          | `/reader-state`                        | 저장·숨김 상태      |
| PUT          | `/reaction`                            | 제한형 사용자 반응  |
| POST         | `/acknowledgement`                     | 필수 확인 증적      |
| GET/POST/PUT | `/api/platform/v1/admin/announcements` | 운영 목록·초안·수정 |
| POST         | `/admin/announcements/{id}/publish`    | 게시 승인           |
| POST         | `/admin/announcements/{id}/archive`    | 보관                |

## 수용 기준

- 노출만으로 읽지 않음 수가 감소하지 않는다.
- 상세를 열면 읽음 상태가 갱신된다.
- 필수 콘텐츠는 숨길 수 없고 확인 전까지 필수 목록에 남는다.
- 역할 대상 콘텐츠는 다른 역할 사용자에게 목록·상세 모두 노출되지 않는다.
- 편집자는 게시·보관할 수 없고 게시 책임자는 초안을 수정할 수 없다.
- 게시 후 원문은 수정할 수 없으며 정정은 새 초안으로 수행한다.
- 홈 위젯은 3건을 넘지 않으며 모든 소식으로 이동할 수 있다.
- 한국어와 영어 셸·피드·상세·관리 화면에 누락 키가 없다.
- 390px 모바일과 1440px 데스크톱에서 가로 오버플로와 텍스트 겹침이 없다.
