> HCM Pilot IA를 적용한다. 아래 Route와 업무 설계는 유지하되 한 Sidebar에 Audience 메뉴를
> 누적하지 않고 `나`, `내 팀`, `HR 운영`, `HCM 관리` Route-derived Surface별 Navigation으로

## HR Home

- H1은 시간대 인사말과 표시 이름을 한 문장으로 유지한다.
- 상단에는 역할과 무관한 장식 Hero 대신 실제 다음 행동과 Context를 배치한다.
- Quick Action은 권한이 있고 실제로 동작하는 최대 여섯 개만 우선 표시한다.
- 개인 신호는 근태 기록, 휴가 잔여, 다음 급여일, 필수 학습처럼 판단 가능한 값만 표시한다.
- Manager Section과 운영 Section은 해당 Audience일 때만 렌더링한다.
- Widget 편집은 허용된 Widget의 표시·순서·크기만 저장하며 보안 권한을 변경하지 않는다.

## 업무별 완료 흐름

- 근태는 예외 숫자만 표시하지 않고 Code·Severity·발생일·설명·해결 상태를 제공하며, 열린
  카드의 해당 날짜 기록으로 바로 이동한다.
- 제출 상태 휴가는 본인이 사유와 함께 철회할 수 있고 Pending Balance가 즉시 복원된다.
- Manager 휴가 화면은 승인 Queue와 향후 60일 팀 부재 일정을 분리해 결정과 Coverage 계획을
  동시에 지원한다.
- Profile, Benefits, Pay, Journey의 지원 행동은 `/hr/services`의 공통 요약을 거쳐 기존
  Employee Service Center 동적 Form으로 이동한다.
- 승인 후 휴가 취소, Benefits 가입 변경, Payroll 명세 원본, LMS 수료는 외부 정책·원장 연결
  전까지 실행 가능한 것처럼 표현하지 않는다.

## 상태 계약

| 상태             | 표현                                                        |
| ---------------- | ----------------------------------------------------------- |
| Loading          | 안정된 Skeleton 크기로 Layout Shift 방지                    |
| Healthy Empty    | 완료된 정상 상태와 다음 가능한 행동을 설명                  |
| Permission Empty | 메뉴 은닉 후 직접 URL도 HR Home으로 복귀                    |
| Partial Failure  | 성공한 Section 유지, 실패 Section만 재시도                  |
| Reference Data   | `REFERENCE` 또는 연결 대기 출처를 명확히 표시               |
| Conflict         | 새로고침이 필요한 Version 충돌·중복 기간을 업무 문구로 설명 |

## 반응형·접근성

- Desktop은 넓은 정보 대시보드가 아니라 업무 밀도에 맞는 12-column Grid를 사용한다.
- Mobile은 Quick Action과 확인할 일을 먼저 두고 모든 표를 읽을 수 있는 목록으로 변환한다.
- 고정 폭 숫자·날짜는 줄바꿈 정책을 명시하며 페이지 가로 스크롤을 만들지 않는다.
- Icon Button은 Accessible Name과 Tooltip을 제공한다.
- 색상만으로 상태를 구분하지 않고 Text·Icon·Label을 함께 사용한다.
