# 01. 기획 정의

## 문제

구성원 디렉터리, Workforce 운영, 개인 인사 업무를 서로 다른 제품처럼 노출하면 사용자는
업무 목적보다 시스템 구조를 먼저 이해해야 한다. 반대로 모든 기능을 한 권한으로 합치면
급여·휴가·인사 데이터의 최소 권한과 직무 분리가 무너진다.

## 제품 결정

1. 사용자 진입점은 DWP HCM의 `인사`/`HR` 앱 하나이며 기본 경로는 `/hr/home`이다.
2. 메뉴는 구성원 Self-service, 실제 Manager, 위임 도메인 관리자 권한을 누적해 편집한다.
3. 개인 화면은 본인의 불변 `person_public_id`와 활성 Worker만 조회한다.
4. Manager 명령은 유효일 보고 관계의 실제 Target Population에만 허용한다.
5. HR 운영은 `TIME_ADMIN`, `ABSENCE_ADMIN`, `BENEFITS_ADMIN`, `PAYROLL_ADMIN`,
   `TALENT_ADMIN`으로 분리하고 `HR_ADMIN`만 전체 도메인을 포괄한다.
6. Tenant Admin과 Provider Admin은 역할 이름만으로 민감 HR 데이터에 접근하지 않는다.
7. Backend 권한, Tenant Scope, Target Population을 매 요청마다 재검증한다.

## 핵심 사용자 여정

| 사용자        | 시작                   | 판단                                      | 명령                                 | 완료 증거                    |
| ------------- | ---------------------- | ----------------------------------------- | ------------------------------------ | ---------------------------- |
| 구성원        | 역할 인지 HR 홈        | 잔여 휴가·근태 상태·다음 급여일·필수 학습 | 근태 저장·제출, 휴가 신청, 목표 갱신 | 최신 상태, 버전, 감사 Event  |
| Manager       | 개인 홈 + 팀 신호      | 제출된 근태·휴가와 예외                   | 승인 또는 사유가 있는 반려           | 결정자·시각·메모·버전        |
| 도메인 관리자 | 허용된 운영 메뉴       | Queue, 예외, 준비 상태                    | 정책에 허용된 운영 조치              | Tenant 감사와 Correlation ID |
| HR Admin      | HR 운영 Command Center | 도메인 간 위험과 정합성                   | 권한 범위 내 조정·승인               | Audit Outbox와 운영 지표     |

## 포함 범위

- 개인 HR Home과 사용자별 Widget 구성
- 개인 인사정보, 근태, 휴가, 복리후생, 급여 명세 참조, 성장·커리어
- 공통 Employee Service Center에 연결된 HR 도움·증명서·인사정보·급여·복리후생 요청
- 실제 Line Manager의 팀 근태·휴가 결정
- 본인 제출 휴가 철회, 근태 예외 설명, Manager의 향후 팀 부재 가시성
- 도메인별 운영 현황과 위임 권한
- People Directory·Organization Graph·Workforce 운영으로의 문맥 유지 이동
- Tenant 격리, Optimistic Lock, 감사 Outbox, 휴가 중복 구간 방지

## 제외 및 외부 결정

- 국가별 Payroll 계산·세금·회계 전표 원장
- 보험사·연금사 Benefits Enrollment 실행
- ATS, LMS, 보상·승계·Calibration의 완전한 원장
- 고객 HRIS Write-back, Credential, Delta/Full Mapping, Reconciliation SLA
- 법정 근로 규칙, 노조·교대·대결·다단계 승인 정책

이 항목은 기능 누락을 숨기는 Placeholder가 아니라 고객·법무·보안·데이터 소유자가 결정해야
하는 출시 Gate다. 내부 화면은 연결되지 않은 값을 합성하지 않고 명시적 연결 상태를 보여준다.
