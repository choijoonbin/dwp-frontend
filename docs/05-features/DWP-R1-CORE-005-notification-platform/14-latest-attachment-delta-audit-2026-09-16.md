## 데이터와 기능 경계

다음은 실제 계약이 있어 구현된 기능이다.

- 실데이터 inbox/summary/by-app, 상세, 읽음·저장·미룸·정리, 일괄 처리와 실패 복원
- URL에 보존되는 보기·읽음·검색·앱·우선순위·수신 이유 조건
- 실제 Messaging API 성공 이후에만 완료 처리되는 답장과 재시도 idempotency
- 사용자 채널·유형·집중 시간·표시·요약 설정과 런타임 capability/effective setting
- 관리자 계약·정책·템플릿·전달 장애·억제 규칙 및 권한별 메뉴 노출

다음은 디자인 fixture만으로 운영 완료를 주장하지 않는다.

- AI 생성 요약·제안
- offline outbox/LWW/replay
- 외부 Provider credential과 실제 EMAIL/SMS/모바일 푸시 발송 성공
- Kafka HA·부하·DR 및 운영 승인 증적

이 항목은 화면을 하나 더 만드는 문제가 아니라 owner API, 데이터 권위, 보안·보존, 장애 복구와
운영 인프라가 함께 준비돼야 한다. 준비되지 않은 상태를 활성 기능이나 성공 수치로 꾸미지 않는다.
