# DWP-R1-AI-001 수용 테스트

| ID    | Given                      | When                    | Then                                           |
| ----- | -------------------------- | ----------------------- | ---------------------------------------------- |
| AC-01 | Ask·Work Permission        | 업무 질문               | 권한 내 Source만 조회하고 Citation과 답변 표시 |
| AC-02 | Ask Permission 없음        | 질문 제출               | Context와 Model 호출 없이 거부                 |
| AC-03 | 급여·민감정보 질문         | 질문 제출               | L3 Handoff, Source·Model 호출 0회              |
| AC-04 | 변경 요청                  | 질문 제출               | L2 Workflow Handoff, Mutation 0회              |
| AC-05 | Source 없음                | 읽기 질문               | 답변 없이 `NO_GROUNDED_SOURCE`                 |
| AC-06 | Model Credential 없음      | Source가 있는 질문      | 합성 답변 없이 `CONFIGURATION_REQUIRED`        |
| AC-07 | Model이 허위 Citation 반환 | 응답 검증               | Grounding 위반으로 보류                        |
| AC-08 | 동일 Request ID·동일 질문  | Retry                   | 저장된 동일 Run 응답                           |
| AC-09 | 동일 Request ID·다른 질문  | 재사용                  | `409` 충돌                                     |
| AC-10 | Runtime Token              | 승인된 두 조회 API      | GET만 허용                                     |
| AC-11 | Runtime Token              | 다른 Workspace API·쓰기 | `401`                                          |
| AC-12 | 감사·DB 확인               | 질문 완료               | 질문·답변·Source 제목 평문 없음                |
| AC-13 | 모순된 Browser 응답        | Contract 검증           | 렌더링하지 않고 안전한 오류                    |
| AC-14 | Desktop·Mobile·Keyboard    | 전체 Ask Journey        | 겹침 없이 상태·Source·Retry 접근 가능          |

## 현재 자동 증적

- Agent Unit/Contract Test 44개 통과
- Gateway Ask Permission Relay와 Platform Runtime 최소권한 Test 통과
- Frontend Ask Response fail-closed Unit Test 통과
- TypeScript, i18n, E2E와 실제 Service Smoke는 Release 검증 기록에서 갱신한다.
