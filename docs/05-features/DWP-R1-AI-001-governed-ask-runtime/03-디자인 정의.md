# DWP-R1-AI-001 디자인 정의

## 원칙

- 대화형 소비자 Chat UI가 아니라 반복 업무를 위한 조용한 Enterprise Workbench로 만든다.
- Policy, Source, Model 상태를 동일 높이의 Operational Strip으로 비교 가능하게 표시한다.
- Answer는 Card 중첩 대신 본문과 좌측 Accent를 사용하고 Source는 스캔 가능한 List로 둔다.
- `Completed`, `Abstained`, `Configuration required`를 색상만으로 구분하지 않는다.
- 긴 한국어·영어 질문, Source 제목과 320px 화면에서 Text가 겹치지 않아야 한다.

## 접근성

- Form Label, Heading 계층, Status Live Region과 Icon Button 이름을 제공한다.
- Keyboard만으로 질문 제출, Retry와 Source 열기가 가능해야 한다.
- Loading Motion은 `prefers-reduced-motion`에서 정보 손실 없이 축소한다.
- 모든 상태는 Light·Dark·High Contrast Token으로 표현한다.
