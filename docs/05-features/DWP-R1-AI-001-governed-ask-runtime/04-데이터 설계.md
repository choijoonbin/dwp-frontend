# DWP-R1-AI-001 데이터 설계

Agent Runtime 전용 `dwp_agent` Database가 실행 증적을 소유하며 업무 원본은 복제하지
않는다.

| Table                | 책임                                                      |
| -------------------- | --------------------------------------------------------- |
| `ai_agent_runs`      | Tenant·사용자·Request별 상태, 정책, 사용량, 지연과 암호문 |
| `ai_model_calls`     | Provider·Model Route 상태, Token, 지연과 Provider ID Hash |
| `ai_agent_citations` | Run별 Source 식별자 Hash와 Source 유형                    |
| `sys_schema_history` | Migration Version, SHA-256 Checksum과 적용 시각           |

## 보호 규칙

- 질문은 Keyed HMAC만 저장한다.
- 재시도 응답은 AES-256-GCM으로 암호화하고 Tenant·User·Request·Run을 AAD로 묶는다.
- 동일 Request ID가 다른 질문 Hash와 재사용되면 `409`로 거부한다.
- 질문, 답변, Source 제목, Prompt, Chain-of-thought는 평문 Table과 기본 Audit에 저장하지 않는다.
- 운영 Key는 KMS/Vault Gate이며 Local Key는 개발 환경 전용이다.

보존 기간, Legal Hold, Partition과 삭제 Job은 실제 규제·Tenant 계약 확정 후 별도
Migration으로 추가한다.
