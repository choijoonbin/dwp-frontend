# DWP-R1-AI-001 기획 정의

## 사용자 문제

업무 데이터가 여러 앱에 흩어져 있어 사용자는 오늘의 병목을 파악하기 위해 화면을
반복 탐색한다. 일반 Chatbot은 권한·근거·최신성을 증명하지 못하고 변경 요청과 조회를
혼동할 수 있다.

## 제품 약속

- 사용자의 유효 Session과 App Permission으로 Source 후보를 먼저 제한한다.
- 근거가 있는 읽기 전용 답변만 제공하고 Source를 함께 표시한다.
- 급여·민감정보와 변경 요청은 Model 호출 전에 차단하거나 승인 Workflow로 인계한다.
- 근거, 설정 또는 권한이 부족하면 그 상태를 숨기지 않고 답변을 보류한다.
- 질문·답변·Source 제목은 기본 감사 로그와 평문 DB에 저장하지 않는다.

## R1 범위

- Work Item과 Productivity Item 조회
- L0·L1 읽기 전용 답변, Citation, Confidence와 실행 증적
- Agent Registry, Idempotency, Model Route 상태, 안전한 감사 이벤트
- 한국어·영어 UI와 Desktop·Mobile 반응형 상태

## 제외 및 Gate

- Tool Mutation, 메일 전송, 승인·권한 변경은 별도 Workflow 계약 전 제외
- Knowledge RAG는 ACL·삭제 전파·평가 Dataset 확정 전 제외
- 실제 OpenAI Model 호출은 운영 Credential, 허용 Model, 예산과 Eval 승인 후 활성화
