# DWP-R1-AI-001 화면 설계서

## 화면 구조

1. Page Header: Ask 목적과 읽기 전용 상태
2. Question Composer: 질문, 추천 질문, 실행 Command
3. Runtime Status: 정책 판정, 조회 Source 수, Model 상태
4. Answer: 사용자 질문, Grounded Answer 또는 명시적 Abstention
5. Sources: 제목, System, 유형과 권한 있는 원본 Link
6. Execution Evidence: Agent Revision, Token, Latency, Audit ID

## 상태

| 상태                        | 표현                                                       |
| --------------------------- | ---------------------------------------------------------- |
| Idle                        | 최근 업무 Context와 추천 질문                              |
| Loading                     | 정책·Source·Model 처리 중임을 하나의 진행 상태로 표시      |
| Completed                   | 답변, Confidence, 1개 이상의 Citation과 완료 Model Route   |
| Abstained                   | 권한·민감정보·근거 부족·Provider 거부 사유와 다음 행동     |
| Configuration required      | Registry·Context·Model 중 준비되지 않은 운영 구성요소 표시 |
| Transport or contract error | 안전한 오류와 Retry, 불완전 응답은 화면에 렌더링하지 않음  |

답변과 실행 Command를 같은 Primary Action으로 표현하지 않는다. 외부 Source는 새 창으로
열고 내부 Route는 현재 Workspace에서 이동한다.
