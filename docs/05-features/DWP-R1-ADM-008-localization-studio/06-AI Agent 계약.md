# DWP-R1-ADM-008 AI Agent 계약

현재 릴리스는 AI 자동 번역이나 자동 게시를 제공하지 않는다.

향후 Agent는 다음 제한 안에서만 동작한다.

- 허용: 누락 Key 탐지, 용어 일관성 제안, 초안 번역 후보와 변경 요약 생성
- 금지: 승인·게시·과거 증거 변경, 검토자 사칭, 외부 TMS로의 무승인 반출
- 필수 근거: 원문 Key, 기존 게시본, 용어집 버전, 사용한 모델과 Prompt 버전
- 필수 확인: 사람이 후보를 편집하고 사유와 함께 기존 상태 전이를 직접 실행

Agent 결과는 번역 진실 원천이 아니며 초안 입력 후보로만 취급한다.
