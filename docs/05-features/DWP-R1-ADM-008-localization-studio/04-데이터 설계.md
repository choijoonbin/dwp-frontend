# DWP-R1-ADM-008 데이터 설계

## 테이블

- `adm_localization_bundles`: `(tenant_id, bundle_key, target_locale)`로 번들을 식별하고
  현재 게시 개정을 가리킨다.
- `adm_localization_revisions`: 원문·번역 JSONB, SHA-256, 상태, 작성·제출·결정·게시자와
  낙관적 잠금 버전을 보존한다.
- `adm_localization_revision_decisions`: 제출·승인·반려·게시·복원 사유의 append-only 증거다.

## 무결성

- 번들마다 `DRAFT`, `IN_REVIEW`, `APPROVED` 열린 개정은 최대 한 건이다.
- 제출된 내용과 SHA-256은 DB Trigger가 변경을 차단한다.
- 결정 증거의 수정·삭제는 DB Trigger가 차단한다.
- 게시와 복원은 과거 행을 변경하지 않고 포인터 변경 또는 새 초안 추가로 처리한다.
- 모든 조회와 변경은 `tenant_id` 조건을 포함한다.

상태와 결정 값은 `PLATFORM.LOCALIZATION.*` 시스템 코드 세트와 소비자 Binding으로
등록한다. 외부 번역 공급자의 세부 Payload는 이 Core 테이블에 저장하지 않는다.
