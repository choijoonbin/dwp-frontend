# DWP-R1-ADM-008 기획 정의

## 문제와 목표

화면 문구를 소스와 배포에만 의존하면 누락 Key, 깨진 placeholder와 검토되지 않은 번역이
사용자에게 바로 노출된다. Localization Studio는 테넌트 번역을 제품 Key 기반 자산으로
관리하고 `초안 -> 검토 -> 승인 -> 게시` 수명주기와 복원 근거를 제공한다.

## 포함 범위

- 제품 영역과 대상 언어별 번들 및 버전 이력
- 원문·번역 Key 편집, 누락·미등록 Key·placeholder 일치 검증
- Fallback 결과, 게시본 대비 Diff와 결정 이력
- 제출자와 결정자 분리, 낙관적 잠금과 사유 필수화
- 승인된 버전 게시, 기존 게시본 대체, 과거 버전의 새 초안 복원
- 테넌트 격리, 변경 감사와 한영 사용자 여정

## 제외 범위

- 외부 TMS의 양방향 동기화와 번역가 과금
- 기계 번역 결과의 자동 승인 또는 자동 게시
- 실행 중인 프론트 번들 파일을 DB가 직접 덮어쓰는 방식

외부 TMS는 버전·충돌·삭제·재시도 정책이 승인된 뒤 별도 Adapter로 연결한다.
