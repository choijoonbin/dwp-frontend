# DWP-R1-ADM-008 디자인 정의

- Page Canvas와 관리센터 Header 계약을 유지한다.
- 번들 목록과 편집 작업공간은 중첩 Card가 아닌 Master-Detail 경계로 구분한다.
- 상태는 색상만으로 구분하지 않고 텍스트 Chip과 명령 가용성을 함께 사용한다.
- 편집 표에는 안정 Key, 원문, 번역과 행별 문제를 같은 읽기 흐름에 배치한다.
- Fallback은 실제 번역과 별도 표식으로 구분하며, Diff는 변경 유형과 전후 값을 제공한다.
- 모든 Icon Button은 tooltip과 접근 가능한 이름을 갖고 Dialog는 제목·설명과 연결한다.
- 주요 명령은 디자인 시스템 `ActionButton`, 입력은 `FormField`, 빈 상태는
  `GuidedEmptyState`를 사용한다.
- 좁은 화면에서는 목록과 작업공간이 세로로 재배치되고 표는 내용을 가리지 않는
  수평 스크롤 경계를 갖는다.
