# DWP-R1-ADM-008 화면 설계서

## 정보 구조

1. 상단 지표는 번들, 열린 초안, 결정 대기, 게시본과 품질 문제를 보여준다.
2. 좌측 번들 목록은 제품 Key·언어·상태·완성도를 스캔 가능하게 제공한다.
3. 우측 작업공간은 `편집`, `변경 비교`, `Fallback 미리보기`, `결정 이력` 보기로
   전환한다.
4. 상태에 허용된 명령만 노출하고 제출·결정·게시·복원은 사유 Dialog에서 확정한다.

## 핵심 여정

- 생성: 번들 Key와 언어를 정하고 첫 원문·번역 Key를 등록한다.
- 편집: 누락과 placeholder 오류를 행 단위로 수정하고 서버 검증 결과를 갱신한다.
- 독립 검토: 작성자가 제출하고 다른 관리자가 승인 또는 구체적 사유로 반려한다.
- 게시: 승인본을 현재 번역으로 활성화하고 이전 게시본은 변경 불가 이력으로 남긴다.
- 복원: 과거 버전을 수정하지 않고 해당 내용에서 새 초안을 만든다.

빈 상태, 로딩, 오류, 충돌과 검증 차단 상태에는 다음 행동을 명확히 제공한다.
