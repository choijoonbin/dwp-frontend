# DWP-R1-ADM-008 수용 테스트

- `V52__create_localization_revision_studio.sql`이 빈 DB와 기존 DB에 적용된다.
- 누락 Key, 알 수 없는 Key와 placeholder 불일치가 검토 제출을 차단한다.
- 완전한 번역만 `DRAFT -> IN_REVIEW`로 전환된다.
- 제출자는 자신의 개정을 승인하거나 반려할 수 없다.
- 승인본만 게시할 수 있고 기존 게시본은 `SUPERSEDED`로 남는다.
- 과거 개정 복원은 해당 행을 변경하지 않고 `based_on_revision_id`가 있는 새 초안을 만든다.
- 제출 후 번역 내용과 결정 증거의 Update/Delete를 DB가 거부한다.
- Stale version과 다른 Tenant의 Bundle·Revision 요청을 거부한다.
- `e2e/localization-studio.spec.ts`의 생성·검증·제출·승인·게시·복원 Journey가
  Chromium과 Mobile에서 통과한다.
- 한영 문구 Key 대칭, Keyboard 조작과 Axe 핵심 규칙이 통과한다.

외부 TMS 동기화는 현재 수용 범위가 아니며 별도 Adapter 계약과 장애·충돌 시험 전에는
출시 완료 증거로 간주하지 않는다.
