# 02 화면 설계서

## Route

- `/admin?view=registry`
- `Administration > Registry`
- 권한: `ADMIN`, `TENANT_ADMIN`, `PLATFORM_ADMIN`

## 정보 구조

- Toolbar: Search, Type Filter, Lifecycle Filter, Refresh, New
- Desktop Grid: Type, Entry, Owner, Artifact Version·Revision, Risk, State, Action
- Mobile List: Type·State, Name·Key, Risk·Version·Owner, Action
- Dialog: Type, Key, Name, Owner Reference, Artifact Version, Risk Tier, Description

## Action

- Draft: Edit, Activate, Retire
- Active: Create Revision, Retire
- Retired Head: Create Revision
- Activate: 기존 Active Revision을 자동 Retire하고 새 Revision을 Active로 전환

Empty, Loading, Error, Permission과 Version Conflict는 공통 Admin Pattern을 사용한다.
