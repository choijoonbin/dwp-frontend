# 03 디자인 정의

- Type, Risk와 Lifecycle은 Label이 포함된 Semantic Chip으로 표현한다.
- 반복 Action은 Lucide Icon Button과 Tooltip을 사용한다.
- 활성화와 폐기는 확인 Dialog를 거치고 Focus를 복원한다.
- Desktop은 Data Grid, Mobile은 Semantic List를 사용해 수평 Scroll을 만들지 않는다.
- Light, Dark, High Contrast와 세 Density를 DWP Token에서 상속한다.
- Figma 연결은 라이선스 준비 시까지 보류하고 Feature ID로 추후 연결한다.
