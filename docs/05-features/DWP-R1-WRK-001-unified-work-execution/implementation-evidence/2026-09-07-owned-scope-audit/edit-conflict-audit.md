# 개인 할 일 편집 충돌 감사 — 2026-09-07

업무 앱 소유의 개인 할 일 편집과 초안 보존 여정을 감사했다. 원본 06의 편집 화면 및 기존 구현의 실제 저장 흐름에서 발견한 결함을 보완한 기록이다. 이 문서와 추가 상태 캡처는 승인 원본 18개 전체의 시각 동일성이나 운영 원천 활성화를 주장하지 않는다.

## 확인한 결함과 변경

1. **최신 버전으로 조용히 승격되는 편집 초안**: 버전 4 편집 중 저장이 409로 거절되면 저장 훅은 버전 5를 읽어 `initialValue`를 갱신했다. 폼은 기존 초안을 보존하면서 다음 저장에는 최신 `initialValue.version`을 사용했으므로, 사용자가 최신 내용을 확인하지 않고 기존 초안으로 덮어쓸 수 있었다. [수정 전 재현 로그](edit-conflict-before.log)에 저장 버튼이 계속 활성 상태인 실패를 보관했다.
2. **명시적인 충돌 검토**: 초안이 시작한 버전을 별도로 유지하고 최신 버전과 다르면 저장을 중단한다. 최신 제목·설명·우선순위·기한·원천 표시·체크리스트를 읽은 뒤 `최신 내용으로 편집하기` 또는 `변경 내용을 확인하고 내 초안 유지`를 선택한다. 선택만으로 저장 요청은 전송되지 않으며, 다시 저장해야 변경된다. 그 사이 버전이 다시 변경되면 재검토한다. 사용자에게 표시할 수 없는 원천 식별자는 노출하지 않는다.
3. **키보드와 확대 상태의 복구 위치**: 최신 내용 영역에는 이름과 키보드 스크롤 포커스를 제공했다. WebKit 200% 확대에서는 검토 선택 후 제목이 포커스만 가진 채 화면 밖에 남는 결함을 `toBeInViewport`로 재현했다. 검토 영역이 제거된 다음 프레임에 제목으로 일반 포커스를 복귀해 화면 위치도 함께 조정했다. [수정 전](edit-conflict-focus-before.log)과 [해당 케이스 재검증](edit-conflict-focus-after.log)을 보관했다.

## 검증 결과

- 관련 단위 테스트 25개, 2개 파일 통과. 신규 회귀는 초안 보존 중 검토 강제, 저장 전 두 번째 충돌, 최신 내용 선택 시 체크리스트 교체 및 이용 불가 원천 보존을 검증한다.
- E2E 매트릭스는 Chromium 및 WebKit에서 1440px, 1280px, 390px 한국어 다크·고대비, 320px 긴 한국어, 1280px의 200% 확대를 실행했다. 10건 중 9건 통과 후 WebKit 확대의 화면 밖 포커스 1건을 수정했고 해당 1건 재실행이 통과했다. 수정 후 전체 10건을 새로 재실행한 결과로 표기하지 않는다.
- E2E는 버전 4 저장 409 → 버전 5 조회 → 명시 검토 → 버전 5 저장 성공까지 검증한다. 선택 시 자동 저장 금지, 다음 쓰기 멱등키 갱신, 초안 또는 최신 설명 유지, 제목의 실제 화면 내 포커스, 가로 넘침을 검사한다. 320px 대화상자는 Axe serious/critical 위반이 없다.
- 수정한 소스 및 테스트 범위 ESLint 통과. [검증·이미지 SHA 매니페스트](edit-conflict-manifest.json)에 추가 상태 캡처 10개의 파일과 크기를 기록했다.
