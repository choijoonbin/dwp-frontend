# 디자인 목표와 실제 구현 확인표

2026-09-07 갱신. 이전의 단일 메뉴 수용 판정은 폐기하며 **6개 메뉴·18개 실제 프레임**을 기준으로 한다. 01–12는 프롬프트 묶음 번호로서 프레임 수와 다르다.

정본 추적표는 [18개 화면 구현 정정·검증](../2026-09-07-design-remediation.md)에 있다. [실행 갤러리](../implementation-evidence/2026-09-07/index.html)와 [검증 manifest](../implementation-evidence/2026-09-07/manifest.json)는 원본 파일과 실행 증거를 항목별로 연결한다.

| 묶음 | 구현                                                                                                                          |
| ---- | ----------------------------------------------------------------------------------------------------------------------------- |
| 01   | 독립 6개 메뉴, 역할별 목록, 검색·필터·정렬·밀도·계획 선택과 실제 조작                                                         |
| 02   | 결재 근거·결재선·양식·이력과 담당 가져오기/승인/반려/보완 요청                                                                |
| 03   | 접근권한 근거·사유·고정된 미리보기·최신 권한/버전 재검증·결정 및 반영 상태                                                    |
| 04   | 서비스 요청·보완 근거·현재 양식·검증·응답·원천 결과; 실테넌트 v6 활성화 대기                                                  |
| 05   | 개인 상태·내용·복수 원천·체크리스트·이력·삭제 확인                                                                            |
| 06   | 생성/캡처/편집 양식·우선순위·기한·체크리스트·원천 검색·입력 보존                                                              |
| 07   | 독립 오늘 계획, 실제 지표·계획/후보·필터·순서 변경·버전 충돌 복구                                                             |
| 08   | Calendar와 수행 시간 검토, event/link 분리·부분 성공 복구                                                                     |
| 09   | 원천별 상태·범위·재조회와 항목별 일괄 결과·지원 제외·제한적 재시도                                                            |
| 10   | 전사 Flow 홈의 실제 개인 업무·계획 기여와 Work 왕복, 서비스 보완 대기의 권한별 Work/Services 진입; 전체 시안 외형과 차이 있음 |
| 11   | 선택 업무 옆 AI 패널·SSE 답변·출처·초안 편집/복사·명시적 적용                                                                 |
| 12   | M1 권한 검토 결정, M2 390/320px 입력 높이 축소·키보드·포커스 여정                                                             |

원본의 실제 모바일은 01–05 및 M1/M2이다. 실제 320px, dark, forced-colors, 200% 프레임은 제출되지 않아 구현과 브라우저 시험에서 별도 검증했다. 예시 수치·첨부·권한 반영·AI 자동 실행을 운영 사실로 하드코딩하지 않는다. [권한 활성화 자료](../2026-09-07-service-response-activation.md)의 정식 릴리스 조건을 완료로 바꿔 표현하지 않는다.
