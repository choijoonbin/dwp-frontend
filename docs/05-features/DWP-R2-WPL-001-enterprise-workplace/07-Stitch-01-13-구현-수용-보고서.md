## 추가된 데이터 운영 기능

전역 근무공간 관리자 메뉴에 `데이터 연계 운영`을 추가했다. Calendar, 실제 재실, 출입,
사이니지, 방문자, 차량, 시설 작업지시 7개 원천의 제공자와 불투명 설정 참조를 관리한다.
설정 저장과 실제 연결 검증을 분리하며 상태는 `NOT_CONFIGURED`, `DISABLED`,
`CONFIGURED_UNVERIFIED` 중 하나로 표시한다.

시설 요청은 다음 운영 데이터를 네이티브 레코드에 저장한다.

- 우선순위
- 담당자
- 처리 업체
- 외부 작업지시 참조
- SLA 처리 기한
- 낙관적 버전, 변경 사유, 확인, 감사 증거

외부 작업지시 참조가 있더라도 제공자 연결 성공으로 간주하지 않는다. 승인된 Adapter가 검증 증거를
제공하기 전에는 외부 센서·출입·방문·차량 데이터를 생성하거나 정상 상태로 표시하지 않는다.
