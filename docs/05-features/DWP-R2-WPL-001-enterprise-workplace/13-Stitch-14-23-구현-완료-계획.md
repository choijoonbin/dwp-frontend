## 2. 실행 순서

### Wave 1 — P0 권위 Read Model과 Provider Truth

1. `/workplace/find?types=ALL`을 14번 Canonical Route로 만들고 기존 Explore·Rooms 진입을 Query 보존
   Redirect로 통합한다.
2. Search·Reservation·Home Projection에 Source별 상태, Coverage, Freshness, Partial failure를
   제공한다.
3. Connector Runtime Truth, Checkpoint, Replay Preview·Job·Receipt를 구현한다.
4. 기존 Workplace 대표 Playwright 회귀를 0건으로 만들고 14·21 수직 여정을 추가한다.

### Wave 2 — P0 예약 실행

1. 16번 통합 내 예약 Projection과 Owner별 허용 명령을 구현한다.
2. BookingIntent, Hold, Batch·Item, Waitlist, AlternativeOffer를 구현한다.
3. Actor와 Beneficiary, TTL, 부분 성공, 보상 선택, Result unknown 재조회를 E2E로 검증한다.

### Wave 3 — P1 현장 경험

1. Visit·Access lifecycle과 예약 연계 ServiceOrder를 구현한다.
2. Published navigation graph, 접근 가능 경로와 Graph 부재 Fallback을 구현한다.
3. Device 등록·Binding·Heartbeat·원격 명령·Room Display·Status Board를 구현한다.
4. AudienceSnapshot과 Safety Incident의 Preview·발령·전달·응답·종료·보고를 구현한다.

### Wave 4 — P2 계획과 예약 도우미

1. 실제 점유와 예약을 분리한 Forecast·Scenario·Emission 모델을 구현한다.
2. 설명 가능한 예약 제안, 권위 API 검증, 명시적 확정, Batch 실행과 재조회를 Agent Tool로
   구현한다.

## 3. 모든 수직 기능의 공통 완료 Gate

- 메뉴와 Route에서 실제 권한으로 도달할 수 있다.
- 화면의 모든 Primary action이 Canonical API에 연결된다.
- Loading, Empty, Partial, Stale, Read-only, Denied, Conflict, Failed, Result unknown과 Recovery가
  동작한다.
- 고위험 쓰기는 Version, Idempotency Key, 영향 Preview, 사유, 명시적 확인, Step-up, Receipt,
  Audit를 제공한다.
- 외부 연계는 Provider·Configuration version과 검증 증거가 일치하기 전까지 `HEALTHY`로 표시하지
  않는다.
- 1440px, 1280px, 390px, 320px, 실제 200% 확대, 키보드, Axe, 고대비, Reduced motion,
  긴 한·영문과 부분 API 실패를 검증한다.
- OpenAPI, Gateway, Product PEP, Frontend client와 Backend 구현이 같은 계약을 사용한다.
