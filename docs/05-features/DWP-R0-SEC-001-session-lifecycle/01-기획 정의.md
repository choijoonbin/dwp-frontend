# DWP-R0-SEC-001 기획 정의

## 문제와 Outcome

- 현재 Session은 로그인·폐기와 절대 만료만 지원해 장시간 방치, Token Replay Window,
  다른 기기 확인·폐기를 사용자가 통제할 수 없다.
- 사용자는 자신의 활성 Browser Session을 식별하고 다른 기기를 폐기할 수 있어야 한다.
- 서버는 활동이 없는 Session을 자동 만료하고 활성 Session의 Token ID를 주기적으로
  교체하되 절대 수명을 연장하지 않아야 한다.

## Persona와 JTBD

| Persona     | JTBD                                                         |
| ----------- | ------------------------------------------------------------ |
| 일반 사용자 | 사용 중인 기기를 확인하고 의심스러운 Session을 즉시 종료한다 |
| 보안 운영자 | Idle·Rotation·폐기 정책으로 탈취 Session의 유효시간을 줄인다 |
| 감사자      | Session 시작·최근 활동·폐기와 실행 주체를 재현한다           |

## Scope

- 절대 Session 수명과 Idle Timeout
- 활동 중인 Session의 Token ID Rotation과 짧은 이전 Token Grace
- 현재 사용자의 Session 목록
- 개별 Session 폐기와 다른 Session 전체 폐기
- 현재 Session 식별, IP·User Agent·시작·최근 활동·만료 표시
- CSRF, HttpOnly Cookie와 서버 Registry 유지

## Non-goal

- 장기 Refresh Token과 Remember Me
- 관리자 전사용 Session Console
- Device Fingerprinting과 위험 기반 인증
- CAEP·Shared Signals 실시간 연동
- Native App Token Lifecycle

## 정책 기본값

| 정책                 | 기본값 | 의미                                             |
| -------------------- | ------ | ------------------------------------------------ |
| Absolute Lifetime    | 8시간  | Rotation으로 연장되지 않는 최대 Browser Session  |
| Idle Timeout         | 30분   | 실제 인증 API 활동이 없으면 만료                 |
| Rotation Minimum Age | 10분   | 더 자주 Rotation해 DB Row를 과도하게 만들지 않음 |
| Previous Token Grace | 30초   | 동시 요청·다중 Tab의 진행 중 요청만 허용         |
| Activity Touch       | 60초   | 매 요청 DB Update를 피하는 최근 활동 갱신 간격   |

Tenant별 정책 기능은 유지하되 R0에서는 Product Configuration으로 운영한다.

## Analytics·Audit

| Event                       | Trigger             | 최소 속성                           |
| --------------------------- | ------------------- | ----------------------------------- |
| `auth.session.created`      | 로그인 성공         | sessionFamilyId, tenantId, userId   |
| `auth.session.rotated`      | Token ID 교체       | familyId, previousIdHash, newIdHash |
| `auth.session.revoked`      | Logout·사용자 폐기  | familyId, actorId, reason           |
| `auth.session.idle_expired` | Idle 검증 실패 추적 | familyId, timeoutPolicyVersion      |

원문 Token은 DB, Log, Analytics와 Audit에 저장하지 않는다.
