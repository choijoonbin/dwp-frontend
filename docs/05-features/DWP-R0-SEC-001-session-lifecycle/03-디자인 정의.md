# DWP-R0-SEC-001 디자인 정의

## Component Mapping

| 역할         | DWP·MUI Component                                      |
| ------------ | ------------------------------------------------------ |
| Page         | Container, Page Heading                                |
| Policy       | Definition List형 Grid, Chip                           |
| Sessions     | 의미 있는 `ul`·`li`, Divider, Stack                    |
| Device       | Lucide Monitor·Smartphone, Typography                  |
| Command      | Button·IconButton가 아닌 명시적 `Log out` Text Command |
| Confirmation | Dialog, Cancel·Log out                                 |
| Async        | Skeleton, Alert, Progress                              |

## Visual Rule

- Page Section을 Card로 감싸지 않는다.
- 현재 Session은 `Current` Chip과 텍스트로 중복 식별한다.
- 위험 Command는 빨간 배경을 상시 사용하지 않고 확인 Dialog의 최종 Command에서만
  Error Color를 사용한다.
- IP와 Timestamp는 Secondary Text로 계층화하되 고대비에서 식별 가능해야 한다.

## Theme·Density

- Light·Dark·High Contrast
- Compact·Standard·Comfortable에서 Row 높이만 변하고 정보 순서는 유지
- Reduced Motion에서 목록 제거 Animation 없이 즉시 갱신

## 접근성

- 목록과 Heading으로 구조 제공
- Color만으로 현재·만료·위험 상태를 전달하지 않음
- Dialog Initial Focus는 Cancel, 최종 파괴 Command는 명시적 Label
- Status 변경은 Toast와 목록 갱신으로 전달
