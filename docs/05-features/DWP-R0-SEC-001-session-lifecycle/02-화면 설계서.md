# DWP-R0-SEC-001 화면 설계서

## Route

- `/account/security`
- Navigation: Account Menu의 `Security & sessions`
- 권한: 인증된 사용자 본인

## 화면 구조

1. Page Header: `Security & sessions`
2. Session Policy Summary: Idle·절대 만료 정책
3. Active Sessions List
4. `Log out other sessions` Command

## Session Row

- Device Category와 Browser·OS를 추정한 Label
- `Current` 상태
- IP Address
- 시작 시각, 최근 활동과 절대 만료 시각
- 현재 Session이 아닌 Row의 `Log out` Command

User Agent 원문은 Tooltip·상세 진단 외에는 그대로 노출하지 않는다. Device Label 추정이
불가능하면 `Unknown browser`로 표시하고 보안 판정 근거로 사용하지 않는다.

## 상태

| 상태         | 표현                                        |
| ------------ | ------------------------------------------- |
| Loading      | 고정 높이 Skeleton Row                      |
| Empty        | 현재 Session 조회 불일치로 Error 처리       |
| Error        | 재시도와 보안 지원 안내                     |
| Revoking     | 해당 Command 비활성화와 진행 상태           |
| Success      | 목록에서 제거하고 짧은 Toast                |
| Current 종료 | Cookie 삭제, 인증 Cache 제거와 Sign-in 이동 |

## Responsive

- Desktop: Device, IP, 활동·만료와 Command를 한 Row로 Scan
- Mobile: Device를 첫 줄에 두고 Metadata와 Command를 다음 줄로 Wrap
- 320px에서도 Command와 시간 문자열이 겹치지 않음

## Keyboard

- Tab 순서는 Page Command에서 Row Command 순
- 각 `Log out`은 Device Label이 포함된 Accessible Name 사용
- 다른 Session 전체 폐기는 확인 Dialog 후 실행
- Focus는 갱신 후 다음 유효 Heading 또는 목록으로 복귀
