# DWP-R0-SEC-001 수용 테스트

## Acceptance Criteria

| ID    | Given                 | When                | Then                                            |
| ----- | --------------------- | ------------------- | ----------------------------------------------- |
| AC-01 | 유효 Session          | 인증 API 활동       | Throttle 간격 이후 lastSeen·idleExpiry 갱신     |
| AC-02 | 30분 무활동           | 다음 인증 요청      | 401이고 Cookie가 유효 Session으로 처리되지 않음 |
| AC-03 | Rotation 가능 Session | Refresh             | 새 jti·동일 sid, 절대·Idle 만료 불변            |
| AC-04 | 이전 Token            | Grace 안·밖 요청    | 안에서는 허용, 밖에서는 401                     |
| AC-05 | 다중 Session          | 목록 조회           | 현재 Session과 다른 기기 Metadata 구분          |
| AC-06 | 다른 Session          | 사용자가 폐기       | Family 전체가 즉시 거부되고 목록에서 제거       |
| AC-07 | 다른 사용자 Family ID | 폐기 시도           | 404이고 대상 Session은 유지                     |
| AC-08 | 다른 Session 전체     | Logout Others       | 현재 Family만 유지                              |
| AC-09 | Security Page         | Desktop·Mobile 탐색 | Keyboard·Axe 위반과 Text Overlap 없음           |
| AC-10 | 원문 Token            | DB·응답·Log 검사    | Access Token 원문이 노출·저장되지 않음          |

## 자동 Test

- Backend Unit: 활성·Idle·절대·Grace Validator
- Backend Service: Rotation, Touch Throttle, Family Revoke와 타 사용자 차단
- Frontend Unit: API Error와 Device Label
- Playwright: 목록·개별 폐기·Logout Others·Axe·Mobile

## 로컬 통합 검증

- PostgreSQL 15에 Flyway V3 적용 및 Lifecycle Column·Index 생성
- Gateway 경유 Login·Session 목록·최소 발급시간 전 무회전 Refresh
- 동일 Family·절대 만료·Idle 만료를 유지하는 실제 JWT Rotation
- 다중 Browser Session 생성 후 Logout Others와 폐기 Token 401
- 현재 Session 폐기 후 Cookie 기반 인증 401

## 수동 Gate

- 두 Tab 동시 Refresh·요청
- Sleep·Wake와 Network Offline 후 복귀
- 200% Zoom, Keyboard, VoiceOver
- 운영 Proxy의 실제 IP Header 신뢰 정책
- Production Secure Cookie와 Key Rotation
