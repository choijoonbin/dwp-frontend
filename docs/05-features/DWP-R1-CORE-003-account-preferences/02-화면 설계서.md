# DWP-R1-CORE-003 화면 설계서

| Route                                     | 질문                                           |
| ----------------------------------------- | ---------------------------------------------- |
| `/account/profile`                        | 내 정보의 원천과 수정 책임은 어디인가          |
| `/account/settings/appearance`            | 화면 모양을 어떻게 사용할 것인가               |
| `/account/settings/accessibility`         | 접근성 동작을 어떻게 맞출 것인가               |
| `/account/settings/language`              | 지역 표시 정책은 무엇인가                      |
| `/account/settings/home`                  | Home에 무엇을 어떤 순서로 볼 것인가            |
| `/account/settings/managed`               | 회사가 관리하는 값과 예외 요청 상태는 무엇인가 |
| `/account/security`                       | 로그인 정책과 활성 Session은 무엇인가          |
| `/admin/experience/preference-exceptions` | 어떤 관리형 설정 예외를 누가 검토해야 하는가   |

Account Sidebar는 업무 Navigation과 분리한다. 변경 Control 옆에 저장 중·저장됨·실패·충돌
상태를 표시하고 실패해도 마지막 서버 값을 임의로 덮지 않는다. Mobile은 Section Navigation을
Drawer로 제공하고 현재 Section과 Workspace 복귀 경로를 유지한다.

관리형 설정은 값·정책 원천·실제 담당자를 읽기 전용 정보로 보여 준다. 예외 가능 Rule에만
요청 Action을 제공하고, 요청 값·업무 사유·영향을 함께 받는다. 관리자 화면은 상태별 업무량,
요청자·설정·값 목록과 근거·영향·증적 상세를 결합한 검토 Workbench다. 승인·반려 후 처리된
항목은 대기 Queue에서 빠지고 해당 상태 View와 사용자 이력에서 확인된다.
