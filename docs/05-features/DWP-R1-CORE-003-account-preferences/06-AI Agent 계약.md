# DWP-R1-CORE-003 AI Agent 계약

개인 설정은 사용자 명시 입력만으로 변경한다. Agent는 Theme, 접근성, Locale, Home Layout,
Session 종료 또는 Login Policy를 자동 변경하지 않는다.

장애·질병·민감 특성을 추론한 설정 변경, Prompt나 업무 내용의 Preference 저장, Tenant 관리형
정책 우회와 사용자 확인 없는 Session 종료를 금지한다.

Agent는 관리형 정책 예외를 자동 요청·승인하거나 승인된 값을 자동 적용하지 않는다. 예외 요청은
사용자의 명시 입력, 결정은 권한 있는 Tenant 관리자의 명시 Action과 근거를 요구한다.
