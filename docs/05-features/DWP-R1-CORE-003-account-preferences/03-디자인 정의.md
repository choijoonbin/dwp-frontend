# DWP-R1-CORE-003 디자인 정의

- 설정은 기능 카드 모음이 아니라 Section Navigation과 조용한 Form Row로 구성한다.
- Binary 값은 Switch, Mode는 Segmented Control, 순서는 명시적 Move Action을 사용한다.
- 관리형 값은 Disabled Control처럼 보이게 하지 않고 값·원천·담당자를 읽기 전용으로 표시한다.
- 예외 요청은 관리형 값 옆의 명시적 Action으로 제공하고, Pending 상태에서는 중복 요청을 막는다.
- 관리자 검토는 KPI Strip, 상태 Filter, `EnterpriseDataGrid`, 상세 Inspector와 근거 Dialog를 사용한다.
- 승인도 즉시 적용처럼 표현하지 않고 통제된 후속 변경의 승인 증적으로 설명한다.
- 자동 저장 상태는 색상에 의존하지 않는 Text와 Live Region으로 알린다.
- Icon은 의미 있는 Section 식별에만 사용하고 장식용 Glass Surface를 반복하지 않는다.
- 320px, 200% Zoom, Keyboard-only, Reduced Motion, High Contrast와 긴 Time Zone을 검증한다.
