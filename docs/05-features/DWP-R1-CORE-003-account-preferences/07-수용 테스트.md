# DWP-R1-CORE-003 수용 테스트

- Platform V47 Schema v2와 V51 관리형 정책·예외 Migration이 적용된다.
- Appearance·Accessibility·Regional·Home 설정이 자동 저장되고 새 로그인에서 복원된다.
- Tenant·User가 다른 Preference를 조회·수정할 수 없다.
- 잘못된 Time Zone, Enum, Widget ID, Payload와 Stale Version을 거부한다.
- 저장 중·성공·실패·충돌 상태가 화면과 접근 가능한 Live Region에 표시된다.
- Profile 원천, SSO/MFA 구성 상태와 Session이 실제 API 값과 일치한다.
- Profile은 언어 표시·변경 Control을 제공하지 않고, 일반 구성원은 `언어 및 지역`에서만 제품 언어를 변경한다.
- 관리형 값은 편집 Control처럼 보이지 않고 담당자와 예외 가능 여부를 실제 정책 API에서 읽는다.
- 사용자는 업무 사유·영향과 함께 예외를 요청하고 Pending 중복을 만들 수 없으며 본인 요청만 취소한다.
- Tenant 관리자는 같은 Tenant 요청만 조회하고 Version·근거·증적과 함께 승인 또는 반려한다.
- 요청·취소·결정·자동 만료가 감사되고 결정 이력 Update·Delete가 거부된다.
- 승인은 설정을 자동 적용하지 않으며 사용자·관리자 화면 모두 이 경계를 명시한다.
- `e2e/managed-preference-exceptions.spec.ts`가 요청→승인→사용자 이력 Journey를 검증한다.
- `e2e/account-preference-ownership.spec.ts`가 일반 구성원의 Profile·언어 설정 소유권을 Desktop·Mobile에서 검증한다.
- Provider Principal은 Home·Managed·Tenant 알림 설정을 보지 못하고 직접 URL·Platform Preference
  API도 거부된다. Tenant Branding·`/api/platform/v1/personal-preferences*` Network 호출은 0건이다.
- Provider 언어는 Auth `preferredLocale`, Appearance·Accessibility·Regional 표시는
  `dwp.provider-preference.v1:provider:<realm>:<user>` Browser Key만 사용한다. 서로 다른
  Realm·User·Tenant Preference와 충돌하지 않고 고객 데이터·지원 Session·Secret을 저장하지 않는다.
- Provider 화면은 `이 브라우저에 저장됨`을 표시하고 Cross-device Server Sync를 성공으로
  표현하지 않는다. Server Sync는 후속 Backend Gate다.
- `e2e/shell.spec.ts`, `e2e/visual.spec.ts`, `e2e/shell-contract.spec.ts`가 통과한다.
- 200% Zoom, Keyboard-only, High Contrast와 Reduced Motion을 검증한다.

실제 IdP MFA·재인증·위험 로그인은 `D-01` 승인 뒤 별도 Sandbox 수용 기준을 적용한다.
