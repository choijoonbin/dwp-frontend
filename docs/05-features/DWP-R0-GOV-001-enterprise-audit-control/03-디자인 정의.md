# 03 디자인 정의

## 방향

감사 화면은 장식적 Dashboard가 아니라 빠른 판단과 반복 조사에 최적화한 Quiet
Enterprise Workspace로 설계한다. 고급스러움은 큰 Card나 과도한 Glass 효과가 아니라
정확한 정보 계층, 밀도, 정렬, 상태 표현과 자연스러운 Detail 전환으로 만든다.

## 시각 규칙

- Page section은 Card 안에 중첩하지 않고 Full-width Band와 Grid로 구성한다.
- Card radius는 8px 이하, 표 Row 높이와 Header 높이는 고정한다.
- Severity는 색만 쓰지 않고 Icon·Label·점수를 함께 제공한다.
- `Critical/High`, `Denied/Failed`, `Healthy`는 의미가 겹치지 않는 Semantic Color를 쓴다.
- Hash, Event ID, Correlation ID는 Monospace와 Copy Action을 제공한다.
- 빈 상태는 데이터가 없는 이유와 다음 가능한 Action만 제시한다.

## Interaction

- 위험 행 Hover는 Layout을 이동시키지 않고 배경·Focus Ring만 바꾼다.
- Refresh·Export·Copy에는 Lucide Icon과 Tooltip을 사용한다.
- Loading은 Grid Skeleton, Error는 Inline Recovery, Mutation은 Button 진행 상태를 쓴다.
- `prefers-reduced-motion`에서는 Drawer·Chart 전환 Motion을 제거한다.

## 접근성 Gate

- WCAG 2.2 AA 대비와 Keyboard 탐색
- Filter·Segment·Dialog의 명시적 Accessible Name
- Data Grid 행 선택과 Detail Drawer Focus 복귀
- 날짜·숫자·상태 Label의 `ko`·`en` Locale 적용
