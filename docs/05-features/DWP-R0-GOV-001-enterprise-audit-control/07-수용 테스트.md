## Release 차단 조건

- Tenant 조건 없는 조회 또는 다른 Tenant ID로 접근 가능
- Secret·Token·Password·Raw Network Identifier 저장
- Source 장애가 정상 업무 Transaction을 Rollback
- Collector 재기동 뒤 Event 유실 또는 중복 증거 생성
- Export 사유·Actor·Hash 누락
- 표 행 높이 이동, Keyboard 접근 불가, 다국어 Key 노출
- Case SLA·Entity 범위·조사 Task·Activity 저널 중 하나라도 누락
- Activity Update·Delete가 가능하거나 Task 상태와 완료 시각이 불일치
- 미완료 Task·빈 Resolution으로 Case 종결이 가능하거나 종료 보고서 Update·Delete가 가능
- Closed Case 또는 연결 Finding·Evidence·Entity·Task·Note를 변경하거나 Case를 재개할 수 있음

## Production Gate

Local acceptance는 외부 인프라 준비를 대체하지 않는다. mTLS/Workload Identity,
KMS/HSM, WORM Archive, SIEM, RLS, Alert와 복구 훈련이 완료되어야 Production Release가
승인된다.
대량 Export의 비동기 운영 승인은 `D-12`의 Queue/Worker·KMS Object Storage·WORM·만료·
장애 재시도 계약과 E2E가 완료된 뒤 별도로 판단한다.
