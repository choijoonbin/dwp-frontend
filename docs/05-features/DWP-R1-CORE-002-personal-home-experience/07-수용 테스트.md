# DWP-R1-CORE-002 수용 테스트

## 1. 기능 Gate

- [x] 로그인 후 `/`에 Personal Home Shell이 보이고 Sidebar가 없다.
- [x] App 실행 후 Business App Shell과 Sidebar가 보인다.
- [x] Product Mark를 누르면 `/`로 복귀하며 Sidebar가 제거된다.
- [x] Header에 이름·직책·Avatar가 체계적으로 배치된다.
- [x] 권한이 없는 App은 Home, Sidebar, Catalog와 Route에서 차단된다.
- [x] App Reorder·Folder를 Pointer, Touch, Keyboard와 Menu로 조작할 수 있다.
- [x] Admin이 문구, 위치, Overlay를 저장할 수 있다.
- [x] PNG·JPEG 배경 업로드와 Built-in 기본값 복원이 동작한다.
- [x] 회사 Logo·회사명을 DWP와 함께 표시하고 Admin에서 업로드·제거할 수 있다.
- [x] 사용자가 Widget 표시·순서를 저장하고 Reset할 수 있다.
- [x] 관리형 공지는 숨길 수 없고 대상·기간에 맞는 게시 공지만 Home에 표시된다.
- [x] Admin이 공지를 Draft로 작성하고 게시·보관할 수 있다.
- [x] Branding의 Shell·Sign-in·Email·Favicon Preview와 Accent 품질 검사가 동작한다.
- [x] Home의 Desktop·Mobile, Light·Dark, 한국어·영문 Preview와 Safe Area 검사가 동작한다.
- [x] 기본 Locale 제목·설명이 불완전한 게시를 UI와 API 모두 거부한다.
- [x] Branding·Home 게시·Asset·Reset 이력과 낙관적 Rollback이 동작한다.
- [x] 공지 상태 Pipeline·검색·Preview·Draft 복제와 View·Action 집계가 동작한다.

## 2. 보안·데이터 Gate

- [x] MIME 위조, 크기 초과와 Path Traversal을 거부한다.
- [x] Media GET도 로그인 Session을 요구한다.
- [x] Client Tenant Assertion이 있으면 Session Tenant와 불일치를 거부한다.
- [x] DB Metadata와 Local File이 Upload·Reset Transaction 결과와 일치한다.
- [x] Version 충돌을 거부하고 Audit Event를 남긴다.
- [x] SVG Script·외부 Resource, 안전하지 않은 공지 Action과 잘못된 게시기간을 거부한다.
- [x] 개인 Layout은 Tenant·User로 격리되고 등록된 App·Widget Schema만 허용한다.
- [x] Experience Revision은 append-only이고 Rollback도 새 Revision·Audit로 남는다.
- [x] 공지 Engagement는 대상 사용자만 기록되고 관리자에게 집계로만 노출된다.
