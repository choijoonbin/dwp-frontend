## 1. 기능 Gate

- [x] 로그인 후 `/`에 Personal Home Shell이 보이고 Sidebar가 없다.
- [x] App 실행 후 Business App Shell과 Sidebar가 보인다.
- [x] Product Mark를 누르면 `/`로 복귀하며 Sidebar가 제거된다.
- [x] Header에 이름·직책·Avatar가 체계적으로 배치된다.
- [x] 권한이 없는 App은 Home, Sidebar, Catalog와 Route에서 차단된다.
- [x] App Reorder·Folder를 Pointer, Touch, Keyboard와 Menu로 조작할 수 있다.
- [x] Admin이 문구, 위치, Overlay를 저장할 수 있다.
- [x] PNG·JPEG 배경 업로드와 Built-in 기본값 복원이 동작한다.

## 2. 보안·데이터 Gate
