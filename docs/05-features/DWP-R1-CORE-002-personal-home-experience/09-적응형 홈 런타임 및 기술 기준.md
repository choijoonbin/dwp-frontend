# DWP-R1-CORE-002 적응형 홈 런타임 및 기술 기준

> 기준일: 2026-08-14
>
> 상태: P0-P3 구현 및 로컬 신규 설치 검증 완료

## 1. 구현 결과

| 단계 | 완료 범위                                                                        |
| ---- | -------------------------------------------------------------------------------- |
| P0   | 사용자 소유 업무 강제, 단일 Home Overview, Section별 권한·장애 격리              |
| P1   | 실데이터 Now·Next·Later Day Rail, 역할별 기본 Widget 순서, Quick Apps            |
| P2   | 근거·출처·신뢰도가 있는 추천, 명시적 피드백, 키보드 편집, Widget Manifest        |
| P3   | Micrometer 지표·감사, 서버 소유 추천 메타데이터, PostgreSQL 18, 런타임 기준 갱신 |

Home은 원천 API를 Widget마다 반복 호출하지 않는다. React Query의 단일
`home-overview` Query가 모든 소비자에 공유되고 각 Section 실패는 해당 영역에만 표시된다.
사용자 피드백은 화면에서 즉시 반영한 뒤 서버 기록과 감사 이력을 남긴다.

## 2. 기술 기준

| 영역               | 채택 기준                                                 | 판단                                        |
| ------------------ | --------------------------------------------------------- | ------------------------------------------- |
| Frontend Runtime   | Node.js 24 LTS, React 19.2, Vite 8, TypeScript 6          | 구현·타입검사·빌드 Gate 대상                |
| Component Platform | Material UI 7.3.11 + MUI X 9.11                           | 현재 조합은 공식 호환 범위, 공통 계약 유지  |
| Backend            | Java 21 Target, Spring Boot 3.5.16, Spring Cloud 2025.0.3 | 전체 모듈 회귀 통과 후 채택                 |
| Agent              | Python 3.14, FastAPI 0.141, `pyproject.toml` + `uv.lock`  | Python 3.11~3.14 호환, 3.14 테스트 통과     |
| Data               | PostgreSQL 18.4, Redis 7.4, Flyway 12.11                  | 신규 전용 Volume과 전체 Migration 재생 검증 |
| Edge               | Spring Cloud Gateway WebFlux, 검증된 세션 Header 전달     | 서비스 Token과 최소 Permission Prefix 강제  |

## 3. 의도적으로 분리한 메이저 전환

- Material UI 9는 안정판이지만 deprecated System Prop 제거가 전체 화면 DOM·스타일에
  영향을 준다. 전 메뉴 Visual Baseline과 접근성 Gate를 갖춘 독립 Migration으로 수행한다.
- Spring Boot 4는 Jakarta EE 11, Jackson 3, JUnit 6과 Starter 모듈화가 함께 바뀐다.
  현재 대규모 도메인 추가와 섞지 않고 3.5 최신 유지보수선에서 경고를 0으로 만든 뒤
  Contract Test를 기준으로 별도 전환한다.
- TypeScript 7은 새 Native Compiler 전환이므로 6을 주 기준으로 두고 CI Shadow Build에서
  Plugin·Storybook·Lint 호환성이 확인된 뒤 승격한다.

이는 미구현 기능 보류가 아니라 Blast Radius가 큰 기반 변경을 제품 기능 검증과 분리한
Release Engineering 결정이다.

## 4. 운영 Gate

- `dwp.home.overview.duration`: Audience별 Home 조합 시간
- `dwp.home.section.degraded`: 원천·상태별 부분 실패
- `dwp.home.recommendation.feedback`: 명시적 피드백 유형
- 권한 밖 앱·업무 노출 0건, 필수 업무 누락 0건
- 320px·Desktop, 한국어·영문, Keyboard와 Axe 중대 위반 0건
- 신규 빈 DB에서 전체 Flyway와 SKAX 씨드 재생 성공
