# DWP-R1-CORE-002 화면 설계서

## 1. Route와 Shell

| Route                                 | Shell               | 주요 영역                       |
| ------------------------------------- | ------------------- | ------------------------------- |
| `/`                                   | Personal Home Shell | Header, App Hero, Today         |
| `/work`, `/ask`, `/activity`, `/apps` | Business App Shell  | Header, Sidebar, 업무 Canvas    |
| `/admin/experience/home-experience`   | Business App Shell  | Home Studio, Preview, 품질·이력 |
| `/admin/experience/branding`          | Business App Shell  | Branding Studio, 채널 Preview   |
| `/admin/experience/announcements`     | Business App Shell  | 상태 Pipeline, Preview, 참여    |

## 2. Home 흐름

1. Header에서 Tenant Logo, DWP Product, Workspace, Search, Notification과 사용자 Identity를
   확인한다.
2. Hero에서 부여된 App을 목적 그룹별로 탐색한다.
3. App Tile을 실행하면 해당 Route와 Business Shell로 이동한다.
4. Sidebar Product Mark 또는 Account Menu Home으로 `/`에 복귀한다.
5. Hero 아래에서 필수 공지, Daily Brief, Focus, Schedule과 Activity를 확인한다.
6. `Edit home`에서 허용된 Widget 순서·표시를 저장하거나 기본값으로 복원한다.
7. `Customize`에서 App 순서·Folder를 저장한다.

## 3. Responsive

- Desktop은 네 App Group을 한 행에 두고 Today 시작점을 첫 Viewport에 남긴다.
- Mobile은 한 Group 단위 가로 Snap과 `All apps` 대체 경로를 제공한다.
- Mobile Home에는 Sidebar·Drawer Trigger를 표시하지 않는다.
- 사용자 이름·직책은 Desktop에 표시하고 Mobile은 Avatar의 접근 가능한 이름과 Menu에서
  확인한다.

## 4. Admin 상태

- Loading, API Error, Default Background, Selected Preview, Uploading, Custom Background,
  Stale Version, Rollback과 Reset 상태를 구분한다.
- 파일 선택은 서버 저장 전 Object URL Preview만 사용한다.
- 저장 후 해상도, 크기, 파일명과 Custom 여부를 표시한다.
- Branding은 Shell·Sign-in·Email·Favicon Preview, Logo 선택·업로드·제거, 조직명과 Accent를
  한 Staging 영역에서 검토하고 품질 Gate 뒤 게시한다.
- Home은 Desktop·Mobile, Light·Dark, 한국어·영문 Preview, Safe Area와 기본 Locale 완전성
  검사를 제공한다.
- 두 Studio는 게시 이력과 Snapshot 요약을 표시하고, 확인 Dialog를 거쳐 과거 Revision을
  새 `ROLLBACK` Revision으로 복원한다.
- Announcement는 Draft, Published, Archived 상태와 대상, 게시기간, 중요도, 고정 여부,
  View·Action 집계를 구분하고 선택 항목 Preview와 Draft 복제를 제공한다.
