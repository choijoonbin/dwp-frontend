# DWP-R1-CORE-002 디자인 정의

## 1. 시각 원칙

- Hero는 실제 Tenant 이미지가 주체이고 App Group은 반투명 정보 Surface로 겹친다.
- Group Surface는 8px 이하 Radius, 얇은 흰색 Border와 제한된 Blur를 사용한다.
- App마다 구분 가능한 Tone을 사용하되 Hero 전체를 단일 Blue Palette로 만들지 않는다.
- Header는 밝고 조용한 Utility Band, Hero는 몰입 영역, Today는 고밀도 업무 영역으로
  역할을 분리한다.

## 2. 안정 치수

- Header: Foundation Header Height
- Hero: Desktop 최소 470px, Mobile Content 기반
- App Glyph: 52px, Tile Width 84~98px
- Group: Desktop 네 Column, Mobile 82vw Snap Track
- Text는 Viewport 비례 Font Scaling을 사용하지 않는다.

## 3. 접근성

- Home Heading은 `h1`, App Group은 `h2`, Today Section은 순서에 맞는 `h2`를 사용한다.
- Drag 외에 Menu·Keyboard Reorder, Folder 생성과 Reset을 제공한다.
- 배경 이미지 위 문구와 Control은 Overlay·Surface로 WCAG AA Contrast를 유지한다.
- Reduce Motion, 200% Zoom, 320px Width와 긴 사용자·Workspace명을 검증한다.

## 4. Tenant 이미지 가이드

- 권장 비율은 3.5:1~4:1, 최소 1600px Width다.
- 중요한 피사체와 문구는 App Surface에 가려지지 않는 Safe Area에 둔다.
- 이미지 안에 필수 안내문을 합성하지 않고 접근 가능한 문구 필드를 사용한다.
- Admin Preview는 실제 Position과 Overlay를 동일하게 적용한다.
