# DWP-R1-CORE-002 AI Agent 계약

## 1. 현재 범위

Home Presentation, Branding, 개인 Layout과 공지 게시 관리는 AI Agent 실행 기능이 아니다.
Tenant Admin 또는 사용자의 명시적 입력에만 반응하며 AI가 Logo, 배경, 공지, 필수 Widget
또는 App 권한을 자동 변경하지 않는다.

## 2. 향후 허용 범위

- Admin이 요청한 문구 초안과 접근성 대체문 제안
- 이미지 Safe Area, Contrast와 해상도 품질 검사 보조
- 대상·기간·표현 위험을 표시한 공지 Draft 제안. 게시에는 관리자 확인이 필수
- 사용자 Daily Brief와 App 추천 이유 생성

## 3. 금지

- 사용자별 민감정보를 배경·문구에 합성
- 승인 없는 Tenant Presentation 게시
- 공지 자동 게시, 사용자 필수 공지 숨김 또는 Layout 강제 변경
- Entitlement를 확대하거나 App을 숨기는 생성형 결정
- 등록되지 않은 HTML, Script 또는 외부 Widget 생성

향후 제안 기능도 Preview, Source·Policy 설명, 사람 확인과 감사 Event를 통과해야 한다.
