# DWP-R1-CORE-006 디자인 정의

## 1. 디자인 의도

Product Management는 별도 제품처럼 보이지 않으면서도 사용자가 5초 안에 `현재 관리 중`임을
알아야 한다. 차이는 장식 Theme가 아니라 정보 구조, 지속 Context와 Action 위험 표현에서 만든다.

- Product Brand와 Accent는 Work와 동일하게 유지한다.
- Header, Sidebar Navigation Collection, Shield Icon, Surface Label, Scope와 Return Action을
  함께 바꾼다.
- Management 전체에 경고색이나 어두운 배경을 칠하지 않는다.
- 색은 상태·위험·정책 잠금의 의미에만 사용한다.
- `관리자`라는 사람 Label보다 `결재 관리`, `HR 운영`처럼 현재 작업 문맥을 표시한다.

## 2. 공통 Component 계약

| Component                  | 책임                                                   | 금지                        |
| -------------------------- | ------------------------------------------------------ | --------------------------- |
| `ProductSurfaceNavigation` | 접근 가능한 Surface Link, 현재 상태, Mobile Disclosure | Local Tab으로 Mode 전환     |
| `ProductManagementLayout`  | Management Header·Sidebar·Main·Return Action           | Work Nav 합성               |
| `ManagementContextBar`     | Product, Tenant, Scope, Read-only, Expiry              | 권한 부여 Control           |
| `ManagementScopeSelector`  | 서버 허용 Scope 선택과 Invalid 상태                    | Tenant ID 직접 입력         |
| `SurfaceAccessState`       | 서버 Authorization Decision의 상태 표현                | Resolver·Content 오류 혼합  |
| `SurfaceRouteNotFound`     | Product-local·Surface-local 404 구분                   | Home Silent Redirect        |
| `SurfaceContentState`      | Policy Lock·Partial Section 상태                       | 인가 실패를 Partial로 표시  |
| `PolicyLockNotice`         | 정책명·출처·Scope·발효일·예외 요청                     | Lock Icon Tooltip만 제공    |
| `SurfaceReturnAction`      | 마지막 허용 Work Route 또는 App Catalog 복귀           | 접근 불가 Work Route로 이동 |
| `SurfaceExpiryIndicator`   | 만료 시각, 5분 전 단일 경고                            | 매초 Live Announcement      |
| `SupportAccessBanner`      | Tenant, Session Scope, Read-only/Write, 사유, 만료     | 일반 Permission과 합산 표시 |

기존 `ProductAdminSurface`는 Page Header Wrapper로만 남길 수 있다. Shell과 Navigation 책임은
`ProductManagementLayout`이 단독 소유한다.

## 3. Product Surface Navigation Anatomy

```text
[Product icon] [결재]  [결재 업무] [결재 관리]  [관리 범위: 전자결재]  [Utilities]
                         └ current link              └ separate control
```

| Element         | 규칙                                                                |
| --------------- | ------------------------------------------------------------------- |
| Product Context | Shell Registry의 번역 Label과 Product Icon                          |
| Surface Label   | Product별 짧은 업무 명칭. `Admin` 단독 영문 사용 금지               |
| Current State   | Text Weight, Underline/Selection과 `aria-current`; 색 단독 금지     |
| Scope           | Surface Link와 12px 이상 시각 간격, 별도 Label                      |
| Expiry          | 만료가 있는 Management Context에만 절대 시각 또는 남은 분 단위 표시 |
| Read-only       | `읽기 전용` Text Badge. Disabled Control마다 이유 제공              |

## 4. Shell Surface Level

- Sidebar와 Header는 `background.paper` 또는 기존 Shell Token을 사용한다.
- Main은 `canvas`, 관련 정보 묶음은 `section`, Dialog·Menu만 `floating`을 사용한다.
- Management라는 이유로 모든 Section을 Card로 만들지 않는다.
- Sidebar Width는 단일 단계면 248px, 여러 관리 Group이 필요하면 272px를 사용한다.
- Compact Rail에서도 Shield/Surface의 Accessible Name을 유지한다.

## 5. Icon과 Color

- Surface Management 표지는 Lucide `ShieldCheck` 계열 17~18px, Stroke 1.8을 사용한다.
- Work로 복귀는 `ArrowLeft` 또는 승인된 Home/Work Icon과 Text를 함께 쓴다.
- Policy Lock은 `LockKeyhole` 또는 승인 Lock Icon + Text를 사용한다.
- Saffron은 만료 임박·주의, Coral은 만료·거부·실패, Teal은 검증 완료에만 사용한다.
- Product Accent는 선택 상태를 나타내고 관리 권한의 위험도를 의미하지 않는다.

## 6. Content Design

| 상황         | 권장 문구                                     | 피해야 할 문구              |
| ------------ | --------------------------------------------- | --------------------------- |
| 현재 Surface | `결재 관리`, `HR 운영`, `HCM 관리`            | `Admin`, `고급 메뉴`        |
| Scope        | `관리 범위: 전자결재`, `운영 범위: 서울 법인` | `Scope 2`, UUID 노출        |
| 만료         | `관리 권한이 17:30에 만료됩니다`              | `세션 오류`                 |
| 권한 없음    | `이 관리 영역에 필요한 책임이 없습니다`       | `접근 실패`, Home 자동 이동 |
| Policy Lock  | `회사 보안 정책에서 관리합니다`               | Lock Icon만 표시            |
| Support      | `승인된 지원 세션 · 읽기 전용 · 18:00 만료`   | `관리자 모드`               |

## 7. 상태별 디자인

### Loading

Surface와 Scope Context는 확정된 Shell 치수로 먼저 표시하고 Navigation은 안정된 Skeleton을
사용한다. Work Navigation을 잠시 보여줬다가 Management로 바꾸지 않는다.

### Empty

권한에 맞는 Menu가 하나도 없으면 빈 Sidebar가 아니라 `Surface Capability 없음` 상태를
표시한다. `APP_CONFIG_ADMIN` Responsibility만 있고 행위 Capability가 없는 경우 필요한 Product
권한 Package를 설명한다.

### Expired

민감 Content를 즉시 제거하고 Page Frame 안에 만료 상태를 표시한다. Pilot에서는 권한 만료 후
저장하지 않은 관리 Draft 본문이나 복사 UI를 표시하지 않는다. 서버에 저장된 Draft도 권한을
재획득하고 Scope·Object 권한을 다시 검증한 뒤에만 조회한다.

### Policy Locked

Control 값은 읽을 수 있어야 하며 다음 Meta를 인접 배치한다.

- 정책 이름과 Owner
- 상속 Source와 적용 Scope
- 발효일 또는 마지막 변경일
- 예외 요청 Route

## 8. Motion

- Surface Link Press: 80~120ms
- Sidebar·Main 전환: 160~220ms Fade/Content replace
- Mobile Drawer: 기존 Shell Motion Token
- Management 진입을 과장하는 Full-screen Animation 금지
- `prefers-reduced-motion`에서는 위치 이동을 제거하고 즉시 상태 변경

## 9. 접근성

- Surface는 Native Link이고 이름 있는 `nav` Landmark에 둔다.
- Icon Button은 Accessible Name과 필요 시 Tooltip을 갖는다.
- `aria-current`, Text, Icon을 함께 사용해 현재 Surface를 나타낸다.
- Scope Menu Option은 Label, Kind, Read-only와 만료를 읽을 수 있다.
- 만료·오류·전환 완료는 중복 Announcement하지 않는다.
- High Contrast에서 Border, Selection, Focus와 Policy Lock이 구분된다.
- 320px, 200% Zoom에서 Header Context가 잘리지 않고 줄임표에는 전체 Accessible Name이 있다.
