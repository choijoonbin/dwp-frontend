# 02 화면 설계서

## Route와 Navigation

- Route: `/admin`
- 진입: 계정 메뉴의 `Administration`
- 권한: `ADMIN`, `TENANT_ADMIN`, `PLATFORM_ADMIN`
- Tab: `Reference data`, `Audit`

## Desktop

- 좌측 Set 목록: 검색, Lifecycle, 항목 수와 갱신 정보
- 우측 Detail: Set Header, Lifecycle Action, Item Table와 Item Action
- Audit: Action, Target, Actor, Outcome, 시각과 Correlation ID Table

## Mobile

- Set 목록과 Detail을 세로 Flow로 배치한다.
- Item과 Audit는 수평 Grid 대신 의미가 보존된 List를 사용한다.
- 주요 Action은 Icon과 Tooltip, 위험 Action은 확인 Dialog를 사용한다.

## 상태

- Empty: 첫 기준정보 생성 Action
- Loading: 안정된 높이의 Skeleton 또는 Progress
- Error: 원인 Message와 Retry
- Conflict: 최신 데이터를 다시 불러온 뒤 변경 재검토
- Permission denied: 공통 403 화면
- Draft·Active·Retired: Text와 Semantic Color를 함께 사용

## Keyboard

Tab 순서는 Search, 목록, Set Action, Item Action 순이다. Dialog는 Focus Trap과 ESC를
지원하고 저장 후 Trigger로 Focus를 복원한다.
