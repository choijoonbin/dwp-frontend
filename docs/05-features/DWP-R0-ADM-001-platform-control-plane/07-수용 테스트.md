# 07 수용 테스트

## 자동 수용 기준

- [x] Admin Role만 `/admin`과 관리 API에 접근한다.
- [x] Gateway Service Identity가 없는 Platform 직접 요청은 `401`이다.
- [x] Set Key와 Item Code가 정규화되고 Tenant 안에서 Unique하다.
- [x] 빈 Set 또는 Label 없는 Item이 있는 Set은 활성화되지 않는다.
- [x] 다른 Tenant의 Key가 같아도 조회되지 않는다.
- [x] Active·유효 Item만 Runtime API에 노출된다.
- [x] 생성·활성화가 Audit에 기록된다.
- [x] Desktop·Mobile 핵심 Flow가 Playwright에서 동작한다.
- [x] Admin 핵심 Flow에 Axe 위반이 없다.

## 수동·운영 Gate

- [ ] Keyboard-only와 200% Zoom 수동 검수
- [ ] Production Service Token Rotation과 Secret Store 연동
- [ ] Proxy 신뢰 경계와 보안 검토
- [ ] PostgreSQL RLS 또는 동등한 격리 방어 검증
- [ ] 감사 보존·Export·Legal Hold 정책 승인

## 회귀 명령

```bash
# backend
./gradlew :dwp-platform-server:test :dwp-gateway:test --no-daemon

# frontend
yarn typecheck
yarn lint
yarn playwright test e2e/admin.spec.ts
```
