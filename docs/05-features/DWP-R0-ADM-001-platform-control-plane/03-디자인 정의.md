# 03 디자인 정의

## Component Mapping

- Shell·Page Header: DWP Shell Pattern
- Search·Tabs·Dialog·Form: MUI Primitive + DWP Token
- Desktop Item·Audit: MUI X Community Data Grid
- Mobile Item·Audit: Semantic List
- Lifecycle·Outcome: DWP Status Chip
- Command: Lucide Icon Button과 Tooltip

## 품질 기준

- 중첩 Card를 사용하지 않고 관리 Surface를 Master·Detail 구조로 표현한다.
- Desktop은 반복 관리에 적합한 정보 밀도를, Mobile은 검토·간단 변경에 적합한
  읽기 순서를 유지한다.
- Light, Dark, High Contrast와 Standard·Compact·Comfortable Density를 상속한다.
- 색상만으로 상태를 전달하지 않고 Label을 병기한다.
- 긴 Key, 한국어·영어 Label과 200% Zoom에서 내용이 겹치지 않아야 한다.

Figma 연결은 사용자 요청에 따라 라이선스 준비 시까지 보류하며, 준비 후 Feature ID와
동일한 Page·Frame 이름으로 연결한다.
