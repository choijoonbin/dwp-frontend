# DWP-R0-UI-001 데이터 설계

## Ownership

- System of Record: Consumer Feature와 연결된 원본 시스템
- DWP 저장 목적: 이 Foundation 자체는 영구 저장 없음
- Tenant 경계: Consumer Query와 API에서 강제, UI Filter로 대체 금지
- 기밀등급·PII: Row와 Citation을 전달하기 전 API에서 Masking·권한 적용

## Entity

| Entity        | 설명                             | Source        | Retention         | Delete·Anonymize |
| ------------- | -------------------------------- | ------------- | ----------------- | ---------------- |
| GridRow       | Consumer가 정의한 표시 Row       | Feature API   | Client Cache 정책 | Query 무효화     |
| Citation      | Source 위치·제목·최신성·ACL 상태 | Search API    | 응답 수명         | 원본 삭제 전파   |
| AgentPlan     | 실행 전 Step·Risk·Approval       | Agent Runtime | 실행·Audit 정책   | Runtime 계약     |
| ExecutionStep | Tool 실행 상태와 결과 요약       | Agent Runtime | Audit 정책        | Runtime 계약     |

## Table

신규 Database Table은 없다. Storybook Fixture는 Source에 정적 Test Data로만 두며
실사용자·고객·기밀정보를 포함하지 않는다.

## 관계와 Lifecycle

- Plan은 1개 이상의 Step과 0개 이상의 Citation을 가진다.
- 승인 전 Plan은 변경 가능하고 승인 후에는 Version과 Hash를 고정한다.
- ExecutionStep은 순서를 보존하며 상태 변경을 덮어쓰지 않고 Audit Event로 남긴다.
- UI의 Sort·Filter는 권한 범위를 넓히지 않는다.

## Search·Vector

- Foundation에는 Search Index·Embedding이 없다.
- Citation은 원본 ACL, Source ID, Version과 Freshness를 반드시 포함한다.
- 원본 삭제·권한 변경 시 Search·Vector 삭제 전파는 Search ADR에서 정의한다.
