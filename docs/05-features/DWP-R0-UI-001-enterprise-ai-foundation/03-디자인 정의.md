## Design System Mapping

## Responsive Rule

| Breakpoint    | Layout                    | Priority            | Hidden·Moved Action |
| ------------- | ------------------------- | ------------------- | ------------------- |
| Desktop 1280+ | Grid·Detail 병렬 가능     | 비교·Bulk Action    | 없음                |
| Tablet        | 한 Column + Detail Drawer | 목록·Primary Action | Secondary Menu      |
| Mobile 320+   | 한 Column·내부 Scroll     | 상태·승인·중단      | 저빈도 Action Menu  |

## Density와 Theme

- Grid Row와 Command 높이는 Compact·Standard·Comfortable Token을 사용
- Light·Dark·High Contrast에서 같은 정보 구조와 Focus 순서를 유지
- Tenant Accent는 Primary Action과 Focus에만 적용하고 Risk·Status 색을 대체하지 않음
- 상태는 Label·Icon·설명으로 중복 표현

## Interaction

| Trigger       | Feedback               | Duration    | Focus            | Reduced Motion |
| ------------- | ---------------------- | ----------- | ---------------- | -------------- |
| Row 선택      | 선택 Surface·Count     | 즉시        | 선택 Row 유지    | 동일           |
| 계획 승인     | Busy·결과 Announcement | 180ms 이하  | 결과 Status      | Fade 제거      |
| 실행 중단     | 확인·Stopping 상태     | Server 기준 | Timeline Heading | 위치 이동 없음 |
| Citation 열기 | Source Preview         | 즉시        | Preview Heading  | 동일           |
