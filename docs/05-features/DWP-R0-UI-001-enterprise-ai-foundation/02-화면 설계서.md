## 화면별 구조

### UI001-S01

- Primary task: Row를 탐색·정렬·선택하고 상태를 비교
- 구조: 제목·결과 수·Grid·Pagination, 고정 높이 Container
- Default Focus: Page Heading 다음 첫 Toolbar 또는 Grid Header
- Keyboard: Tab으로 Grid 진입, Arrow Key로 Cell 이동, Space로 선택
- Mobile: Column Priority를 적용하고 Grid 내부 Scroll을 사용

### UI001-S02

- Primary task: AI 계획의 근거·Risk·변경 대상 검토 후 결정
- 구조: AI Label, Risk, 설명, Step, Source, 승인 Command
- Default Focus: Plan Heading, 결정 후 결과 Status로 Focus 이동
- Mobile: 승인·반려 Command를 한 줄에 억지로 배치하지 않음

### UI001-S03

- Primary task: 실행 Step, 실패와 복구 Action 추적
- 구조: 상태 Timeline, Tool, 시간, 결과, Audit ID, Stop·Retry·Handoff
- Screen Reader: 상태 변경은 `aria-live=polite`, 실패는 명시적 Text와 Icon 사용

## 접근성

- Landmark·Heading 순서를 유지하고 Icon-only Command에 Label·Tooltip 제공
- Grid는 Library Keyboard Model을 유지하며 임의 Key Handler로 덮어쓰지 않음
- Color 외에 Text·Icon·상태 이름으로 Risk와 실행 상태 전달
- 200% Zoom과 320px에서 Command·긴 Source명이 겹치지 않아야 함
- High Contrast에서 선택, Focus, Error Boundary를 식별 가능하게 유지
