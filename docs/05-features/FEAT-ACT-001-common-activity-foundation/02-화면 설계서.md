# 화면·상호작용 계약

| 표면               | 사용자 질문 / 주 행동                              | 현재 구현과 후속 디자인                                   |
| ------------------ | -------------------------------------------------- | --------------------------------------------------------- |
| 기존 활동 홈       | 연결된 실행이 현재 어떤 상태인가 / 사건 열기       | 현재 원장 summary와 최근 사건. 독립 홈의 최종 축소는 후속 |
| 기존 활동 타임라인 | 정확히 어떤 사건인가 / 검색·선택·원본 열기         | 서버 필터와 페이지, 독립 상세. Work 내 배치 디자인은 후속 |
| 공통 상세          | 사실·현재 상태·근거가 무엇인가 / 검증 후 원본 이동 | Activity와 DWAI·ON에서 같은 컴포넌트 사용                 |
| Flow 신호          | 확인할 현재 실행이 있는가 / 이력 열기              | 과거 사건 집계 제거. 완성형 예외 영역 디자인은 후속       |
| DWAI·ON 실행       | 어떤 실행을 요청했는가 / 선택 실행 확인            | `?run=UUID`가 최근 목록 밖 실행도 독립 조회               |

공통 상세는 `apps/dwp/src/components/activity/`에 두어 제품 feature끼리 직접 의존하지 않는다. 상세를 읽기 위해 Work 전체 권한을 부여하지 않는다.

## 호환 경로

- `/activity`, `/activity/home`, `/activity/timeline` 보존.
- `/activity/timeline?event=...` 및 `/activity/events/:eventId`는 정확한 ID 상세 조회.
- Agent UI ID는 충돌 방지용 `dwaion:<UUID>`, 원천 API ID는 UUID.
- `/dwaion/activity?run=<UUID>`에서 공통 상세 표시. 현재 목록 필터·최근 100개 여부와 무관하다.
- 저장뷰 키 `workspace.activity`, 기존 `q/actor/state` 유지. source/object/execution/from/to/includeUsage 추가. 조건 변경 시 cursor 초기화.

## 필수 상태

loading, 정상 빈 목록, 필터 빈 결과, 조회 실패, 원천 일부 실패, 갱신 지연, 권한/삭제/없는 ID의 공통 unavailable, UNKNOWN, 감사 미연결, LEGACY를 구분한다. 일부 원천 실패 시 성공한 원천의 읽기는 보존하되 전체 건수를 표시하지 않고 전역 다음 페이지를 중단한다. cursor 거절 시 ‘최신 페이지’로 복구 가능하다.

원본 열기는 상세를 다시 조회한 후, 권한 검증된 로컬 route에만 이동한다. 저장된 과거 route나 첫 번째 다른 사건으로 대체하지 않는다. DWAI·ON 원본 안에서는 자기 자신으로 다시 이동하는 버튼을 표시하지 않는다.
