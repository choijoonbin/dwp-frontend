# 기획 정의

## 사용자와 성과

주 사용자는 자신의 업무 변경 또는 위임한 AI 실행을 확인하는 직원이다. 질문은 “어떤 일이 실제로 발생했고, 현재 무엇을 확인할 수 있으며, 다음에 어디로 가야 하는가?”이다. 종료 상태는 정확한 사건/실행을 식별하고 권한 있는 원본으로 이동하는 것이다.

이번에는 메뉴 수나 카드 수를 늘리는 대신 조회 신뢰성을 확보한다. 글로벌 제품의 알림 정리 기능은 기존 알림 앱에서 다룬다. 캘린더의 시간 계획·참석 응답과 활동 사건의 발생 시각은 다른 개념이다.

## 범위

- 자체 Workspace TASK 변경 및 앱 사용 사실의 원본 결속, 실제 감사 참조, 데이터 분류.
- DWAI·ON 실제 실행 원장의 현재 snapshot 연결.
- 원본 ACL, 서버 필터/페이지, 독립 ID 상세, 재방문 계약.
- 현재 실행 집계와 과거 이력을 분리하고 Flow의 잘못된 과거 사건 집계를 제거.
- 향후 Work/Flow 배치를 위한 공통 상세 컴포넌트와 디자인 요청서.

제외: 새 업무/알림/일정 원장, 활동 화면에서의 승인·재시도·취소 명령, 모든 외부 서비스의 이력 수집, 관리자 감사 열람권한 확대, 메뉴 삭제, 운영 활성화.

## 측정

출시 필수 조건은 권한 밖 사건 노출 0건, 잘못된 ID 대체 0건, 확인 불가능한 집계를 정상 0으로 표시하는 경우 0건이다. 발견 시간·올바른 원본 도달률·불필요한 앱 전환의 사용자 기준값은 아직 측정하지 않았다. ROI·개선율을 실측 결과로 주장하지 않는다.
