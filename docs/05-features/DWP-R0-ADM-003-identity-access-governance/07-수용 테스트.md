실제 Gateway 검증에서 정상 조회·변경 `200`, Tenant 불일치 `403`, 자기 변경과 낡은
Revision `409`를 확인했다. Database에서 Session 폐기, Revision 증가와 Audit Snapshot을
확인한 뒤 임시 사용자·Role·Session·Audit 데이터를 모두 제거했다.

Organization·Group·SCIM·SoD·Access Review는 Baseline 완료 후 별도 수용 기준으로 확장한다.
