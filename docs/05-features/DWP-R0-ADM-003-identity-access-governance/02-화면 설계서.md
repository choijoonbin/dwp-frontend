# 02 화면 설계서

- Route: `/admin/identity/access`, `/admin/identity/access-reviews`,
  `/admin/identity/provisioning`
- 접근 제어 Toolbar: 사용자 검색, Refresh, 사용자 수와 상태 Signal
- 접근 제어: 사용자, Email, Status·MFA, Effective Role, 직접·Group Source, Scope,
  마지막 로그인, 활성 Session과 Access Revision
- Role Dialog: Tenant의 Active Role Checkbox, Session 종료 영향과 저장
- 접근 검토: Campaign 상태·기한·진행률, Reviewer Queue, Assignment Snapshot,
  Privileged·최근 사용·결정론적 권고와 필수 결정 사유
- 프로비저닝: Connector Readiness와 건강 KPI, 지원 Resource·Attribute Mapping 계약,
  Secret Rotation·Lifecycle, 최근 SCIM Event와 실패 증적 Inspector
- 현재 로그인 사용자의 편집 Action은 비활성화하고 Tooltip으로 이유를 제공한다.
- Role 변경이 대상 사용자의 Active Session을 종료한다는 영향을 Dialog에 표시한다.
- 저장 성공 후 User 목록과 통합 Audit를 갱신한다. Access Review의 과거 Snapshot은 다시
  계산하거나 덮어쓰지 않는다.
- `sm` 미만에서는 Data Grid를 Mount하지 않고 Semantic List만 Render해 0px Grid 오류와
  불필요한 Layout 비용을 방지한다.

Loading, Healthy Empty, Error, Partial, Conflict와 Permission은 기존 Admin Pattern을
재사용한다. 실제 IdP가 결정되지 않은 환경은 연결 성공을 만들지 않고 `D-01` 안내 상태를
표시한다.
