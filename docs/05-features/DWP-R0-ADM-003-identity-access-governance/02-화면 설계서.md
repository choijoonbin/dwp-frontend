# 02 화면 설계서

- Route: `/admin?view=access`
- Toolbar: 사용자 검색, Refresh, 사용자 수
- Desktop: 사용자, Email, Status·MFA, Role, Access Revision, Action Grid
- Mobile: 사용자 Identity, 상태, Role과 Action List
- Role Dialog: Tenant의 Active Role Checkbox와 저장
- 현재 로그인 사용자의 편집 Action은 비활성화하고 Tooltip으로 이유를 제공한다.
- Role 변경이 대상 사용자의 Active Session을 종료한다는 영향을 Dialog에 표시한다.
- 저장 성공 후 User 목록과 통합 Audit를 갱신한다.
- `sm` 미만에서는 Data Grid를 Mount하지 않고 Semantic List만 Render해 0px Grid 오류와
  불필요한 Layout 비용을 방지한다.

Loading, Empty, Error, Conflict와 Permission은 기존 Admin Pattern을 재사용한다.
