# DWP-R1-CORE-004 디자인 정의

## Archetype

- 운영형 Control Workbench
- 정책은 상단의 한 개 경계 Surface, 지표는 얇은 KPI Strip, 요청은 비교 가능한 Grid,
  증거는 Inspector로 구성한다.
- 장식용 Hero, 중첩 Card, 의미 없는 차트와 대형 아이콘은 사용하지 않는다.

## 시각 계약

- 상태는 색상만으로 표현하지 않고 중앙 Display Dictionary의 한영 Label을 함께 쓴다.
- Blocker는 경고색 Outline Chip, 실행 준비는 성공 Alert로 구분한다.
- Hash와 Watermark는 monospace로 표시하되 줄바꿈되어 작은 Viewport를 넘지 않아야 한다.
- 취소는 위험 Action, 재시도는 Governor 전용 Primary Action이다.
- `FileLock2`, `ShieldCheck`, `Clock3` 등 Lucide Icon을 사용하고 Icon Button에는 Tooltip과
  접근 가능한 이름을 제공한다.

## 반응형·접근성

- 320px에서 정책 Chip과 Action은 줄바꿈하고 Grid만 의미상 필요한 축의 스크롤을 가진다.
- Dialog의 Label·Description·초점 복귀를 공통 `FormDialog` 계약으로 제공한다.
- Desktop·Mobile에서 Axe serious/critical 0건, Keyboard-only 생성·취소가 가능해야 한다.
- 200% Text-size에서 제목, 정책 설명과 증거가 겹치거나 잘리지 않아야 한다.
