# DWP-R1-CORE-004 기획 정의

## 문제와 목표

인력 데이터의 즉시 CSV 다운로드는 화면 권한을 우회하고 수신자, 목적, 범위, 마스킹,
보존과 재배포 책임을 잃게 한다. 이 기능은 다운로드 버튼을 만드는 대신 요청 시점의
권한 경계를 불변 Snapshot으로 고정하고 처리·취소·만료의 증거를 남기는 통제형 반출
수명주기를 제공한다.

## 포함 범위

- DB 등록 Dataset과 허용 Selection Key의 동적 탐색
- 조직 Target Population, Field Group과 `EXPORT` Action의 서버 재검증
- 목적, 책임 수신자, 권위 요청 참조와 Idempotency Key
- Masking Profile, Watermark, TTL, 최대 자동·수동 재시도의 정책 Snapshot
- `BLOCKED_PENDING_APPROVAL`, Queue, 실행, 재시도, 취소, 완료, 만료 상태
- 요청·산출물 SHA-256, 크기와 append-only 처리 Timeline
- 개인 요청과 Tenant Governor 전체 검토의 권한 분리
- Team Saved View 소유권 이관·보존·삭제 거버넌스와 연결

## 제외 범위

- 승인 전 실제 파일 생성 또는 다운로드 URL 제공
- 브라우저에서 인력 행을 모아 CSV로 직렬화하는 방식
- KMS, Object Storage, Queue와 WORM을 흉내 낸 로컬 성공 상태
- 자유 형식 SQL, 임의 Column 선택 또는 정책 Snapshot 사후 수정

실제 반출은 `D-09`의 역할·마스킹·수신자 정책과 `D-12`의 Queue, KMS Storage,
만료·삭제 책임이 승인된 뒤 Adapter로 활성화한다.
