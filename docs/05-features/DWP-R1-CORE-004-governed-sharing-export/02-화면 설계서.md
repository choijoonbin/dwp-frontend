# DWP-R1-CORE-004 화면 설계서

## 정보 구조

`/workforce/exports`는 설명용 Dashboard가 아니라 반복 운영을 위한 Control Workbench다.

1. 정책 평가 영역: Dataset, 현재 Population, Field Group, Masking, TTL과 Release Blocker
2. 운영 지표: 차단, 실행 중, 증거 완료 수
3. 요청 목록: 상태·범위·수신자·요청 시간 비교와 선택
4. Evidence Inspector: 목적, 선택 조건, 정책 경계, Hash, 보존과 처리 Timeline
5. 결정 Dialog: 취소 또는 제한된 수동 재시도 사유

## 핵심 흐름

- 조직 Intelligence에서 반출을 요청하면 `view`, 유효일, 비교일, Scenario와 Root 조직을
  URL로 전달하고 Dataset 허용 Key만 Preview에 사용한다.
- 사용자는 수신자, 목적과 권위 참조를 입력한 뒤 요청을 기록한다.
- Gate가 닫힌 경우 요청은 성공으로 보이지 않고 `승인 전 차단` 상태와 `D-09`, `D-12`
  근거를 표시한다.
- Desktop은 목록 옆 Inspector, Mobile은 Drawer를 사용한다. 선택·닫기·취소 후 목록의
  폭과 위치는 이동하지 않는다.

## 화면 상태

- Loading: Dataset과 요청 목록을 독립적으로 대기한다.
- Empty: 반출 요청이 없음을 알리고 상단 주 행동은 한 번만 제공한다.
- Error: Dataset/목록 또는 Preview 실패를 해당 영역에 국소 표시한다.
- Permission: 메뉴와 직접 Route 모두 `DATA.WORKFORCE:MANAGE` 없이는 진입하지 못한다.
- Blocked: 기능을 숨기지 않고 승인되지 않은 실행 경계를 명확히 보여준다.
- Partial: 요청 목록이 있어도 선택 요청 Timeline 실패는 Inspector에만 한정한다.

목록은 고정 높이의 `EnterpriseDataGrid`를 사용하고 모바일에서 페이지 전체의 수평
스크롤을 만들지 않는다.
