# DWP-R1-CORE-007 근거 및 글로벌 벤치마크

> 조사 기준일: 2026-08-21
>
> 접근 범위: 공개된 공식 제품·접근성 문서
>
> 사용 원칙: 외부 화면·Asset·문구를 복제하지 않고 동작 Pattern과 Trade-off만 DWP 계약으로
> 재설계한다.

## 1. 사용자 문제

현재 Home에서 페이지를 스크롤하다가 세로 스크롤이 가능한 Widget 위에 포인터가 멈추면 다음
Wheel·Trackpad 입력을 Widget이 소비한다. 사용자는 페이지 아래로 계속 이동하기 위해 포인터를
빈 공간으로 옮겨야 한다. Widget 내용도 탐색해야 하므로 내부 스크롤을 단순히 차단하는 것만으로는
충분하지 않다.

동시에 현재 Home은 다음 문제를 가진다.

- 로그인 직후 앱별 알림을 확인하고 자주 쓰는 앱을 실행하는 원래 목적이 업무 우선순위와 분리돼
  있다.
- 동일한 사각 Widget과 긴 텍스트가 반복되어 실제 중요도·시간 흐름·변화가 빠르게 구분되지 않는다.
- 대형 배경과 반투명 Group이 면적을 사용하지만 업무 상태를 설명하지 않는다.
- 사용자는 편집 기능을 이미 갖고 있으나 조직 정책과 안전한 개인 자유도의 경계가 충분히
  드러나지 않는다.

## 4. DWP 합성 결정

### 유지

- 권한이 있는 앱만 노출하고 앱별 알림·상태를 확인한 뒤 즉시 실행한다.
- Tenant 기본 Group, 사용자 Pin·Reorder·Folder와 전체 Apps 경로를 유지한다.
- 명시적 편집, Long Press, Drag, 메뉴·Keyboard 이동, 저장·취소·초기화를 유지한다.
- Registry Component, Entitlement, 관리형 공지와 감사 경계를 유지한다.

### 전환

- 전체 화면 배경 Hero를 첫 정보 계층으로 사용하지 않는다.
- 앱은 제거하지 않고 `My App Dock`이라는 안정된 실행 계층으로 압축한다.
- 일정·업무·승인의 실제 시간 관계를 `Today Flowline`으로 표현한다.
- Widget의 내부 세로 Scroll 대신 요약·행 예산·전체 보기와 페이지 Scroll을 사용한다.
- 차트는 추세·비교·분포·임계값처럼 판단을 돕는 실제 데이터가 있을 때만 사용하고 텍스트 또는
  표 대체를 제공한다.

### 기각

- 자유 좌표·픽셀 기반 Canvas와 임의 HTML·JavaScript·CSS
- 사용자를 빠져나오지 못하게 하는 같은 축의 중첩 Scroll
- 알림 수, 긴급도와 업무 상태를 색상이나 Animation만으로 전달
- AI의 무승인 Widget 이동·삭제·권한 변경
- 근거가 없는 장식 차트, 연속 Animation과 대형 마케팅 Hero

Event와 Baseline을 확정한다.

## 7. 자료 사용 기록

- 관찰일은 모두 2026-08-21이다.
- 공개 공식 문서의 기능 Pattern만 요약했다.
- 외부 Screenshot, Component Source, Asset과 문구를 저장소에 복사하지 않았다.
- 사용자 제공 Home Screenshot은 문제 이해를 위한 내부 입력이며 배포 Asset이나 구현 지시로
  취급하지 않는다.

## 8. 검증 범위와 한계

이번 준비는 글로벌 공식 제품 문서 비교, UX·접근성·아키텍처·Delivery 관점의 내부 다중 Expert
Agent 교차 감사와 Figma Desktop 시각 검증을 포함한다. 외부 상용 Design AI 제품에 화면이나 내부
자료를 실제 제출해 평가받은 증거는 없으며 그렇게 표현하지 않는다.

외부 AI 비교 검증이 필요하면 Tenant·사용자·업무 데이터를 제거한 별도 Prototype과 평가 Rubric을
승인한 뒤 수행한다. 외부 AI의 점수나 제안은 Product·Design·Security·Accessibility Owner 승인을
대체하지 않는다.
