# DWP-R1-ADM-007 화면 설계서

| Route                                 | Archetype | 대표 사용자     |
| ------------------------------------- | --------- | --------------- |
| `/admin/platform/navigation`          | Studio    | Tenant Admin    |
| `/admin/identity/app-access-requests` | Workflow  | Access Reviewer |
| `/apps`                               | Catalog   | 구성원          |

Navigation Studio는 게시 Version에서 Draft를 만들고 Tree·Label·권한을 편집한다. Desktop·Mobile,
Locale, Role Preview와 Validation을 확인한 뒤 게시한다. 취소·복원은 확인과 감사 근거를 요구한다.

사용자는 앱 상세에서 목적·기간을 입력해 요청하고 Pending 요청을 취소한다. Reviewer는 요청자·
앱·근거·기간을 비교해 승인 또는 반려한다. 승인 상태와 실제 IAM 적용 대기를 다른 Signal로
표시한다.

No Draft, Validation Error, Stale Version, Empty Queue, Pending, IAM Pending, Rejected,
Cancelled, Expired와 Permission 상태를 구분한다.
