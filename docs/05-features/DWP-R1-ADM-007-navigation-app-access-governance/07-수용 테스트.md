# DWP-R1-ADM-007 수용 테스트

- Platform V45, V46, V48, V59와 Auth V40, V44 Migration이 적용된다.
- Draft는 Tenant당 하나이고 Published Snapshot은 수정되지 않는다.
- 잘못된 Route, Label, Permission, 중복 Key와 Stale Version은 게시를 차단한다.
- Runtime은 게시 Revision만 사용하고 취소 Draft를 노출하지 않는다.
- 사용자는 자신의 요청만 조회·취소한다.
- App Catalog Admin은 전체 Queue를 읽지만 결정·이행할 수 없다.
- Approver는 결정만, Access Manager는 이행·재시도·회수만 수행한다.
- 요청자 자기 승인·이행과 동일 요청 승인자의 이행이 차단된다.
- 승인만으로 앱 권한이 생기지 않고 이행 성공 후 Auth Entitlement가 `ACTIVE`가 된다.
- 이행 실패는 `FAILED`로 보존되며 재시도할 수 있다.
- 회수·만료 후 다음 권한 계산부터 앱 Permission이 제외된다.
- `e2e/wave3-governance.spec.ts`의 요청→검토와 Navigation 게시·복원 Journey가 통과한다.
- Desktop·Mobile·Keyboard와 Validation Error 상태의 시각 회귀가 통과한다.

DWP Auth 내부 부여·회수는 현재 수용 범위다. 외부 Entra·Okta 부여·회수·Reconciliation은
`D-16` Sandbox Gate 이후 별도로 수용한다.
