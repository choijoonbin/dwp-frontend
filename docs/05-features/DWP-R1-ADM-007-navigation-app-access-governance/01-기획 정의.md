# DWP-R1-ADM-007 기획 정의

Navigation을 즉시 수정하거나 앱 요청을 곧바로 권한 부여로 처리하면 검토·복원·감사와
외부 IAM 정합성을 잃는다.

## 목표

- Navigation을 Draft·검증·Preview·Publish·Restore Revision으로 운영한다.
- 사용자의 앱 접근 요청, 독립 승인, 실제 권한 이행·회수 상태를 분리한다.
- 다국어, 역할별 Visibility, Version 충돌과 감사 근거를 한 Journey에서 관리한다.
- 앱 소유·설정·승인·이행·검토 책임을 리소스 범위로 위임한다.

## 제외 범위

- 외부 Entra·Okta Entitlement Mapping과 Reconciliation
- 고객별 다중 관리자 승인 정책
- Drag 조작만 가능한 편집 방식

DWP Auth 내부 Entitlement는 승인 후 별도 이행으로 부여·회수한다. 외부 IAM은 `D-16`
계약 전까지 DWP 내부 적용과 구분하며 외부 적용 성공을 합성하지 않는다.
