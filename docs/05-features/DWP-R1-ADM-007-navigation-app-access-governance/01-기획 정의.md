# DWP-R1-ADM-007 기획 정의

Navigation을 즉시 수정하거나 앱 요청을 곧바로 권한 부여로 처리하면 검토·복원·감사와
외부 IAM 정합성을 잃는다.

## 목표

- Navigation을 Draft·검증·Preview·Publish·Restore Revision으로 운영한다.
- 사용자의 앱 접근 요청과 관리자의 결정을 실제 IAM 적용과 분리한다.
- 다국어, 역할별 Visibility, Version 충돌과 감사 근거를 한 Journey에서 관리한다.

## 제외 범위

- 승인 후 외부 IAM Entitlement 부여·회수
- 고객별 다중 관리자 승인 정책
- Drag 조작만 가능한 편집 방식

외부 IAM은 `D-16` 계약 전까지 `IAM_SYNC_PENDING`으로 명확히 표시한다.
