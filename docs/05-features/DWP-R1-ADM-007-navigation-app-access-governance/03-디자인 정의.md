# DWP-R1-ADM-007 디자인 정의

- Studio는 Tree 편집, Preview와 Validation을 연결하고 저장 Form의 나열로 만들지 않는다.
- Reviewer Queue는 요청 근거·기간·위험을 비교할 수 있는 Grid와 Inspector를 사용한다.
- Lifecycle은 색상만이 아니라 상태명과 다음 행동을 함께 제공한다.
- Move Up/Down, Parent 선택과 Keyboard Action으로 Drag의 대체 경로를 제공한다.
- Mobile Preview는 실제 Shell 폭을 보존하고 화면 안의 화면을 과도하게 축소하지 않는다.
- 320px, 200% Zoom, 긴 Label, Keyboard-only와 High Contrast를 검증한다.
