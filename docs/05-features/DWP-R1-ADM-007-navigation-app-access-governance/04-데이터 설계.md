# DWP-R1-ADM-007 데이터 설계

`adm_navigation_revisions`는 Tenant별 하나의 mutable Draft와 불변 Published Snapshot을
저장한다. `baseline_tree_hash`, `tree_payload`, `validation_payload`, `version`, 게시 Actor와
시각을 보존한다. Lifecycle은 `DRAFT`, `PUBLISHED`, `SUPERSEDED`, `CANCELLED`다. Runtime은
게시 Revision만 소비한다.

`usr_workspace_app_access_requests`는 `(tenant_id, user_id, app_key)` 범위의 요청, 목적,
요청 만료, 결정 근거, Actor와 Version을 저장한다. 요청 Lifecycle의 Pending, Approved,
Rejected, Cancelled, Revoked, Expired와 별도로 이행 Lifecycle의 Not Required, Pending,
Succeeded, Failed, Revoked, Expired를 보존한다. 이행 시도 횟수, 마지막 시각·오류,
이행·회수 Actor와 사유를 덮어쓰지 않고 기록한다.

승인은 제품 Workflow 결과이며 실제 권한 적용 성공을 뜻하지 않는다. Auth의
`com_principal_resource_grants`가 사용자·그룹, 앱 Resource, Permission, Source Reference,
유효 기간, 회수·만료와 Revision을 소유한다. `(tenant, source_type, source_ref)`는 멱등성과
감사 연결 키다. Platform은 요청 Workflow를, Auth는 런타임 Entitlement를 소유한다.

외부 IAM Assignment와 Drift Reconciliation Evidence는 `D-16` Adapter가 별도로 소유한다.
