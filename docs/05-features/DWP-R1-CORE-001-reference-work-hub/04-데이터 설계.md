# DWP-R1-CORE-001 데이터 설계

## 1. Reference 원칙

초기 합성 Fixture 단계는 종료했다. 현재 Workspace Projection은 Platform DB의 Tenant·User
Scope Table과 실제 API를 사용한다. 고객 원천 시스템을 직접 소유하지 않고 원본 ID·Route를
유지하며, 외부 Connector 계약이 확정되기 전에는 DWP Projection과 Preview 범위를 넘지 않는다.

Home 개인 배치와 Saved View는 서버에 저장하고 `version`으로 다중 Device 충돌을 거부한다.

## 2. View Model

| Model             | 핵심 Field                                                                 |

| `TodayItem`       | id, type, title, reasonCode, priority, dueAt, source, actionRoute          |
| `ScheduleItem`    | id, title, startsAt, endsAt, provider, joinUrl                             |

| `AskAnswer`       | id, question, answer, confidence, generatedAt, sources, nextAction         |

| `ActivityEvent`   | id, actorType, state, title, workObject, source, tool, auditId, occurredAt |

E2E Fixture ID는 운영 Entity ID처럼 오해되지 않도록 별도 고정 UUID·Reference Key를 사용한다.

## 3. 현재 저장 구조

| Table                                           | Scope·역할                                                               |
| ----------------------------------------------- | ------------------------------------------------------------------------ |
| `wrk_items`                                     | Tenant·Assignee 업무 Projection, 원본 Reference, 상태와 낙관적 `version` |
| `wrk_activity_events`                           | Tenant·사용자 가시 범위의 사람·시스템·Agent 사건과 Audit Reference       |
| `adm_workspace_apps`                            | Tenant App 계약·Entitlement Resource·Launch·Health Metadata              |
| `usr_workspace_app_preferences`                 | Tenant·User별 Pin·최근 실행·실행 횟수와 `version`                        |
| `usr_home_preferences`                          | Tenant·User별 Home Layout JSON Schema와 낙관적 `version`                 |
| `usr_saved_views`, `usr_saved_view_preferences` | Surface별 개인·Tenant View와 기본값·최근 사용                            |

Work 일괄 변경은 최대 50건의 `(workItemId, version)`을 한 Transaction으로 잠그고 검증한다.
중복 ID나 한 건의 Version 충돌도 전체 변경을 Rollback하며 각 성공 변경은 Activity와 Audit에 남긴다.

## 5. 보안·Privacy

- Fixture에는 실제 이름, 메일, 문서 제목, IP와 고객 식별자를 넣지 않는다.
- 실제 Projection은 Tenant와 User Scope를 모든 Key와 Query에 포함한다.
- Analytics에는 질문 원문, 메일 본문과 Citation Title을 기본 저장하지 않는다.
- 원본 삭제·권한 변경 Event가 Projection·Search·Cache에 전파되는 SLO를 별도 승인한다.
- AI 학습 재사용은 기본 금지이며 별도 명시 동의와 정책 없이는 허용하지 않는다.

## 6. Cache·Freshness 후보

- Today Summary: 1~5분 또는 Event Invalidated
- Work Status: 30~60초 또는 Event Invalidated
- Activity: 현재 60초 Polling, 서비스별 Outbox/Replay 계약 `D-07` 승인 후 Streaming 전환 검토
- App Registry: 15분, 권한 변경 즉시 Invalidated
- Ask Source: Version과 `updatedAt`을 답변마다 표시

수치는 운영 확정값이 아니며 Connector Spike와 Pilot 부하 측정 후 승인한다.
