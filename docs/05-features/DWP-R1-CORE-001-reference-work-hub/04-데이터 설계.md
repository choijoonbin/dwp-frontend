# DWP-R1-CORE-001 데이터 설계

## 1. Reference 원칙

이번 Package는 Frontend 합성 Fixture만 사용한다. 운영 Table, Vector, Search Index와
Message Topic을 추가하지 않는다. 실제 데이터 모델은 Design Partner의 System
Inventory, ACL과 Data Owner 승인 뒤 별도 Feature Migration으로 만든다.

App 개인 배치는 R0.5 Reference에서 `tenantId:userId` Scope의 Local Storage에만 저장한다.
운영 Table이 아니며 서버 동기화·다중 Device 충돌 처리는 R1 API 계약 승인 후 구현한다.

## 4. 보안·Privacy

- Fixture에는 실제 이름, 메일, 문서 제목, IP와 고객 식별자를 넣지 않는다.
- 실제 Projection은 Tenant와 User Scope를 모든 Key와 Query에 포함한다.
- Analytics에는 질문 원문, 메일 본문과 Citation Title을 기본 저장하지 않는다.
- 원본 삭제·권한 변경 Event가 Projection·Search·Cache에 전파되는 SLO를 별도 승인한다.
- AI 학습 재사용은 기본 금지이며 별도 명시 동의와 정책 없이는 허용하지 않는다.

## 5. Cache·Freshness 후보

- Today Summary: 1~5분 또는 Event Invalidated
- Work Status: 30~60초 또는 Event Invalidated
- Activity: Streaming 또는 5~15초 Polling, 연결 해제 시 마지막 Event 시각 표시
- App Registry: 15분, 권한 변경 즉시 Invalidated
- Ask Source: Version과 `updatedAt`을 답변마다 표시

수치는 운영 확정값이 아니며 Connector Spike와 Pilot 부하 측정 후 승인한다.
