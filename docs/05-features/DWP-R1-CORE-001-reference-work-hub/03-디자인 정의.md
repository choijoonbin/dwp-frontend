# DWP-R1-CORE-001 디자인 정의

## 1. 방향

Reference Work Hub는 운영 도구처럼 조용하고 빠르게 Scan되어야 한다. Marketing Hero,
장식용 Gradient, 과도한 대형 Card와 App 아이콘 벽을 사용하지 않는다. 정보 밀도는
높이되 Group, Divider, Typography와 Semantic Status로 구분한다.

## 2. Foundation

- Token Source: `libs/design-system/src/tokens/dwp.tokens.json`
- Theme: Light, Dark, High Contrast와 Density 계약 유지
- Font: Product·Tenant 관리 값, 일반 사용자 임의 선택 제외
- Accent: Product -> Tenant 허용값, 일반 사용자 Color Preset 제외
- Navigation: Product·Tenant Pattern, 일반 사용자 Layout 변경 제외
- Radius: 기본 4~8px, 반복 Item과 Tool Container에만 사용
- Motion: 상태 이해에 필요한 짧은 Transition만 사용하며 Reduce Motion 준수

## 3. Layout

| Surface      | Desktop                                     | Mobile                         |
| ------------ | ------------------------------------------- | ------------------------------ |
| Shell        | 248px Sidebar, 64px Header                  | 64px Header, Drawer Navigation |
| Page Content | `maxWidth=xl`, 24~32px Section Gap          | 16px Gutter, 24px Section Gap  |
| Today        | Priority 2fr + Schedule 1fr, Brief Full Row | Single Column                  |
| Work         | Full-width Grid와 Detail                    | Compact Priority Column        |
| Ask          | Query와 Answer 2fr + Source 1fr             | Query, Answer, Source 순서     |
| Apps         | Responsive 2~4 Column Repeated App Item     | 1~2 Column                     |

## 4. Component Mapping

| 목적               | Component                                  |
| ------------------ | ------------------------------------------ |
| Navigation         | MUI `List`, `ListItemButton` + Lucide Icon |
| Mode·Status Filter | MUI `ToggleButtonGroup`                    |
| Work Queue         | `EnterpriseDataGrid`                       |
| Citation           | `SourceCitationList`                       |
| Action Preview     | `AgentPlanPreview`                         |
| Feedback           | Global Toast, `Alert`, Inline Status       |
| App Launcher       | Repeated `ButtonBase` Item, no nested Card |

## 5. Content와 상태

- Action은 동사로 시작하고 실제 가능한 결과만 약속한다.
- AI 생성 내용은 `AI generated preview`, Source와 최신 시각을 함께 표시한다.
- Priority는 High·Medium·Low Text와 Icon을 함께 사용한다.
- Synthetic Data는 Screen Reader도 인지할 수 있는 `Reference data` Label을 둔다.
- 빈 상태에 기능 설명이나 사용법을 길게 쓰지 않고 현재 결과와 Command만 제공한다.

## 6. Figma 계약

Starter Plan의 다중 Mode 제한이 해소되면 Token Mode를 먼저 구축하고 다음 Frame을
연결한다.

- `R1/Today/Desktop`, `R1/Today/Mobile`
- `R1/Work/Desktop`, `R1/Work/Mobile`
- `R1/Ask/Desktop`, `R1/Ask/Mobile`
- `R1/Apps/Desktop`, `R1/Apps/Mobile`

Figma에서 임의 색·간격을 추가하지 않고 Code Token과 Component Mapping을 기록한다.
