# DWP-R1-CORE-001 수용 테스트

## 1. Acceptance Criteria

| ID    | Given                     | When                   | Then                                                |
| ----- | ------------------------- | ---------------------- | --------------------------------------------------- |
| AC-01 | 인증된 사용자             | Shell 탐색             | Home·Work·Ask·Activity·Apps와 현재 Route가 일관됨   |
| AC-02 | Mobile Viewport           | Navigation Open        | 동일 목적지가 Drawer에 있고 Content와 겹치지 않음   |
| AC-03 | Today Fixture             | Priority Item 선택     | 이유·Source·기한과 Work Action이 표시               |
| AC-04 | Work Fixture              | Status Filter 변경     | 결과 수와 Queue가 일치하고 Layout Shift가 없음      |
| AC-05 | Ask 질문                  | Submit                 | 정책, Source, Grounded Answer 또는 명시적 보류 표시 |
| AC-06 | 근거 부족 Fixture         | Ask Submit             | 확정 답변 대신 Abstention과 Handoff가 표시          |
| AC-07 | App 검색                  | Keyword 입력           | 이름·설명·Owner 기준 결과만 표시                    |
| AC-08 | App Launch                | 권한 App 선택          | Reference Launch Feedback만 있고 외부 변경이 없음   |
| AC-09 | Activity Fixture          | 주체 Filter·Event 선택 | 주체·상태·대상·Tool·Audit ID가 일관되게 표시        |
| AC-10 | Blocked Agent Event       | Detail 확인            | 차단 이유와 사람의 다음 Action이 있고 실행은 없음   |
| AC-11 | Keyboard·Screen Reader    | 주요 Journey 탐색      | Heading·Landmark·Focus·Name·State 위반이 없음       |
| AC-12 | Light·Dark·High Contrast  | Desktop·Mobile Render  | Text·Command 겹침과 Color-only 상태가 없음          |
| AC-13 | Reduced Motion            | Live 상태 Render       | 반복 Motion 없이 동일한 상태 정보를 인지            |
| AC-14 | Source Tree·Network       | Reference Flow 실행    | 허용된 읽기 경로 외 업무 Mutation 호출이 없음       |
| AC-15 | 일반 사용자 Preferences   | 설정 탐색              | Font·임의 Color·Navigation Layout Control이 없음    |
| AC-16 | 인증·CSRF가 유효한 사용자 | Ask Plan Preview 요청  | L2·Approval·Audit ID와 Mutation 금지가 표시         |
| AC-17 | Session 또는 CSRF 없음    | Agent Preview 요청     | 각각 401·403이고 내부 Identity Header 위조가 실패   |
| AC-18 | Service Identity 없음     | Agent 직접 요청        | 누락·불일치는 401, 서버 설정 누락은 503             |
| AC-19 | Agent Plan 응답           | Client 계약 검증       | Plan Hash·Correlation 필수, 변조 Hash는 거부        |
| AC-20 | App Entitlement 변경      | Home 재진입            | 권한 밖 App·Folder 잔여 항목이 노출되지 않음        |
| AC-21 | Home App 사용자           | Drag 또는 Arrange Menu | 그룹 내 순서·폴더 결과가 동일하고 새로고침 후 유지  |
| AC-22 | Keyboard·Touch 사용자     | App 배치 변경          | Pointer Drag 없이도 모든 배치 Command를 완료        |

## 5. 구현 및 검증 증적

- 구현 Route: `/`, `/work`, `/ask`, `/activity`, `/apps`
- Global Shell: Desktop Sidebar·Rail·Top Navigation, Mobile Drawer
- 데이터: Home·Activity Reference와 실제 Workspace API가 공존하며 Ask 계약은
  `DWP-R1-AI-001-governed-ask-runtime`에서 별도 검증
- E2E: Home → Work → Ask → Activity → Apps 핵심 Journey와 제한 상태 검증
- Home E2E: 권한 필터, Menu·Pointer Folder 생성, 이름 변경, 저장·초기화 검증
- 접근성: Desktop·Mobile Axe 자동 검사 및 Semantic Heading·Landmark 검증
- Visual: Shell·Home Light/Dark·핵심 Route의 Desktop·Mobile 23개 Baseline 직접 검토
- 외부 영향: Ask는 읽기 API와 Model Route만 호출하며 Reference Action은 Mutation 없이 종료
- 최종 자동 검증: Unit 23, App E2E·Visual·Axe 39 통과·3개 조건부 Skip,
  Storybook E2E·Visual·Axe 8 기존 Gate 통과
- Build·License: Production·Storybook Build와 Production Dependency 105개 License Gate 통과
- 실제 Session Smoke: CSRF 발급 → Local Login → Logout 모두 HTTP 200 확인
- 실제 Agent Smoke: Login → Session 재검증 → L2 Plan Preview → Logout 모두 HTTP 200 확인
- Agent Contract: Service Identity·Plan Hash·Correlation과 Redacted Audit Event 검증
- Negative Smoke: Session 없는 위조 Identity 401, CSRF 없는 Mutation 403, Agent Service
  Identity 누락·위조 401 확인
