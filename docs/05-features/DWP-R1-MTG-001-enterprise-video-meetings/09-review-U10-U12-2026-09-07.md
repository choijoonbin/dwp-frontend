## 왜 원본과 달라졌는가

1. U10은 조직/개인 및 버전 태그, 선택 카드, 4셀 개요와 3셀 거버넌스, 모바일 타임박스·추천 블록을 단순 목록/텍스트로 축약했다. 기존 테스트는 승인 원본과 반대로 모바일 배너의 gradient/shadow가 없을 것을 강제했다. 한 개 템플릿만 있는 검증 데이터도 전체 목록 구성의 손실을 가렸다.

4. 실제 연결이 없는 수치를 꾸며내지 않는 것은 맞지만, 그 이유로 설계된 블록 자체를 삭제한 것은 잘못이었다. 이번에는 블록 안에 실제 상태 또는 명시적인 미제공 상태를 표시한다.
