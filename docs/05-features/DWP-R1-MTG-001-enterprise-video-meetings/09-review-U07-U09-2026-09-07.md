## Data and interaction contract

Presentation retains existing owner-service authorization, report/source binding, write fences, versioned mutation receipts and unavailable/error states. No example meeting, person, confidence percentage, certification or successful provider stage is invented.

U07's public TypeScript summary appeared to contain organizer and host role, but the actual history wire projection did not. The new browser organizer-filter journey proved this was not a fixture problem: `VideoMeetingDtos.history()` omitted organizer/viewer role and hardcoded both media flags to false; `normalizeHistory()` also replaced organizer with an empty string and host authority with false. The root integrator corrected the additive backend/API projection for `organizerUserId`, `organizerName`, `participantRole` and explicit `canHost`; the adapter accepts legacy absent fields without inferring authority. The browser organizer/date/order/search/reset journey now passes on both devices. Merely adding example names to browser fixtures would not have fixed the product. Media flags remain conservative because governed artifact availability must not be inferred. The wire projection still does not contain favorites, independent review counts, shared-with-me classification or per-record retention deadline. Those require a Meeting-owned projection and persistence before their original controls can honestly become active. Supported filters are applied to the visible authorized page and their scope is stated.

U08 already has cited decisions, actions, summary, topics and meeting-level climate in the authorized report. Those fields can and should be presented without new backend work. Timestamp actions use the existing playback synchronization context. An unavailable recording retains its media/evidence block with its actual status.

U09's Work projection contains canonical task state, ownership IDs, due date, priority, source identity and capability booleans. The Meeting report supplies cited candidate text. It does not supply approved assignee display names, percentage confidence, checklist entries or a supported Work detail deep link. These need explicit upstream contracts. Human promotion remains unavailable until the existing current-authority gate is supplied; rendering an attractive active control cannot substitute for authorization.
