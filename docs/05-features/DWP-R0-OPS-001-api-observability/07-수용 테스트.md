# 07 수용 테스트

## 자동·로컬 Gate

- [x] Gateway, Auth, Platform, People, Provider, Agent Hop이 중앙 테이블에 기록된다.
- [x] Gateway에서 생성한 Trace가 내부 Auth 검증과 대상 Service까지 연결된다.
- [x] Query, Body, Authorization, Cookie, Raw IP와 Raw User-Agent가 저장되지 않는다.
- [x] 동적 Path 식별자는 Placeholder로 정규화된다.
- [x] Service 선언과 Event Batch가 다르면 수집을 거부한다.
- [x] Collector 호출은 재귀 수집되지 않는다.
- [x] Tenant 조건과 서명 Cursor로 목록·상세를 격리한다.
- [x] 월 Partition 생성, Index와 90일 Retention 함수가 적용된다.
- [x] 관리자 Desktop·Mobile UI와 Trace Drawer가 렌더링되고 Axe 검사를 통과한다.
- [x] Java, Python, TypeScript, ESLint, i18n과 Production Build Gate를 통과한다.
