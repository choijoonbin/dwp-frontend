# 03 디자인 정의

- 운영 화면답게 장식보다 밀도, 비교, 상태 식별을 우선한다.
- 성공·경고·오류 Color는 의미 전달에만 사용하고 Text·Icon을 함께 제공한다.
- KPI와 Chart는 정해진 높이를 유지해 Refresh 때 Layout Shift가 발생하지 않는다.
- Grid Row 높이와 숫자 Tabular Variant를 고정한다.
- 상세 정보는 중첩 Card 대신 Drawer의 Definition List와 Trace Timeline으로 구성한다.
- Desktop·390px Mobile, Light·Dark, Keyboard와 WCAG 2.2 AA를 검증한다.
