# 02 화면 설계서

## 정보 구조

Control Center의 `Governance > API monitoring`에서 제공한다.

1. 기간·관측점·서비스·Method·결과·검색 Filter
2. 총 요청, 분당 처리량, 서버 오류율, p95/p99, 활성 Route KPI
3. 요청·오류 Trend와 상태 코드 분포
4. 호출량 상위 Route
5. 고정 Row 높이의 요청 이력 Grid
6. 선택 요청의 Metadata와 Trace Hop 우측 Drawer

Mobile에서는 Filter와 KPI를 세로 재배치하고 목록을 Scan 가능한 항목형 View로 전환한다.
자동 새로고침은 명시적 Switch로 제어하며 수동 새로고침을 항상 제공한다.
