# 04 데이터 설계

## 저장소

`dwp_platform.sys_api_history` 월별 Range Partition에 33개 Metadata Column을 저장한다.
상세 Column, Index와 Retention 계약은 상위 ADR을 따른다.

## 불변식

- Partition Primary Key는 `occurred_at + history_id`다.
- Tenant 관리자 Query는 항상 `tenant_id`를 포함한다.
- Body, Query String, Credential, Raw IP와 Raw User-Agent Column은 존재하지 않는다.
- 상태·Actor·Auth·관측점은 Check Constraint의 허용값만 저장한다.
- Trace/Span과 HMAC Hash는 길이·Hex 형식을 수집 전에 검증한다.
- 기본 90일 보존과 월 단위 Partition Drop을 사용한다.
